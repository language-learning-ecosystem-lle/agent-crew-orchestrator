# Круг ревью самопропускается по ОТСТАВШЕМУ `refs/pull/N/merge`: перевешивание метки этот класс не лечит, лечит только движение головы

**Тред:** `191-watcher-run-may-never-start`. **Дата:** 2026-09-14. **Предмет:** PR #413 (запись
предела гарантии в шапке `notifier-watch.yml`).

Находка родилась не в предмете треда, а на его доставке: #413 нёс запись и стоял под кнопкой john,
а круг ревью на нём не состоялся дважды подряд по двум РАЗНЫМ причинам. Вторая из них и есть запись.

## Что случилось

Круг `34836883802` (событие `pull_request`) закончился **зелёным** за **40 секунд** и не создал
`verdict.md` — погасли разом все три доставки. Причину называет предупреждение самого прогона,
дословно:

```
##[warning]Skipping action due to workflow validation: Workflow validation failed. The workflow
file must exist and have identical content to the version on the repository's default branch.
```

`claude-code-action` пропустил сам себя — гард против промпт-инъекции правкой воркфлоу. Класс
известен и записан раньше; новым оказался **механизм расхождения**.

## Механизм: расходится merge-ref, а не ветка

**Гард сверяет файл того дерева, которым ЕХАЛ ПРОГОН, — а для события `pull_request` это
`refs/pull/N/merge`, не голова ветки и не её база.** Замер (три `rev-parse`, рука curator, msg-001
треда; я его перепроверил на своей стороне):

| ревизия | блоб `claude-review.yml` |
| --- | --- |
| `origin/main` (`970957c3`) | `d7c5c84a` |
| `refs/pull/413/merge` — **им шёл прогон** | `37770131` |
| `refs/pull/413/head` (`80b8f39f`) | `0f98404d` |

Родители merge-ref называют дату его сборки: `Merge 80b8f39f… into c21c1940f…`, **`09:21:47Z`** — то
есть против базы времён #418. После этого в `main` сели пять коммитов, среди них **#417**
(`efd461c2f`, `10:53:38Z`), правящий ровно `claude-review.yml`.

**Ключевое: GitHub НЕ пересобирает merge-ref на каждый merge в `main`.** Он пересобирается, когда
двигается голова PR (и не всегда/не сразу — на движение базы). У стоячего PR, чей merge-ref старше
починки воркфлоу, круг едет СТАРЫМ воркфлоу — и самопропускается.

## Почему «перевесить метку» этот класс не лечит

Событие `labeled` — единственный подъём круга, но оно merge-ref не пересобирает. Перевешивание на
стоячей голове поднимает круг тем же старым деревом, и гард срабатывает снова. **Это прямо
противоположно указанию, действовавшему в треде до сих пор** («головы стоящих PR трогать нельзя,
достаточно перевесить метку»): оно верно для красноты от запасной учётки (#417/#418) и НЕВЕРНО для
самопропуска по валидации воркфлоу. Две разные болезни с одним симптомом «одобрен, но вердикта нет»,
и вторая стоит по кругу (~$1) за каждую слепую попытку.

Цена уплачена дважды: круг `34776682181` (13.09, красный — запасная учётка) и круг `34836883802`
(зелёный и пустой — merge-ref).

## Чем случай опознаётся — и чем НЕ опознаётся

**Не годится эвристика по каталогу.** Проверка «правит ли PR воркфлоу», сделанная диффом от базы
слияния по `.github/workflows/`, на #413 НЕ ПУСТА (`notifier-watch.yml`) — прочитанная буквально, она
говорит «PR правит воркфлоу → ревью человеческое навсегда». Ложь: **гард сверяет ОДИН файл,
`claude-review.yml`**, которого #413 не касается вовсе.

**Не годится и блоб ГОЛОВЫ ветки** (моя первая версия этой записи мерила им). Здесь он случайно
согласился с ответом, но критерий гарда — дерево прогона, а голова им не является.

**Годится блоб merge-ref, и это одна команда на PR, до метки:**

```
git fetch -f origin refs/pull/<N>/merge:refs/tmp/<N>merge
git rev-parse refs/tmp/<N>merge:.github/workflows/claude-review.yml
git rev-parse origin/main:.github/workflows/claude-review.yml
```

Совпали — метку вешать можно. Не совпали — сперва двигать голову. Второй, даровой признак постфактум
— **длительность круга: 40 с против настоящих 4–5 минут.**

Этот же замер снимает кажущееся противоречие, которое я держал открытым полтакта: круги на #388
(`34828011351`, 5 мин 33 с), #411 (`34829936500`, 5 мин 17 с) и #410 (`34830276558`, 4 мин 21 с) шли
ПОЛНУЮ длительность, хотя блоб их ГОЛОВ не был равен блобу `main`. Противоречие мнимое: они ехали
своими merge-ref, собранными в момент, когда те `main` ещё соответствовали. Мерить надо было не то.

## Что сделано

`git merge origin/main` в ветку + ff-push (без force, номер PR цел): `80b8f39f` → `b36abc10`.
Слияние чистое, вклад цел — проверено патчем вклада против КАЖДОГО родителя, а не диффом деревьев:
против `80b8f39f` пусто (вклад не тронут), против `970957c3` (`main`) — `42 0` по `notifier-watch.yml`.

Все три машинные посылки шапки #413 перемерены против НОВОЙ базы и уцелели: ровно один путь в
`git diff --name-only origin/main`, `--numstat 42 0` (удалений ноль), `yaml.safe_load` головы равен
`yaml.safe_load` `origin/main`. Тело PR править не пришлось — и это само по себе доказательство, что
влитие базы написанного о базе не обнулило.

Метка `review` снята: голова уехала, и доставленный 13.09 `approve` ею осиротел (дверь и до того
читала его как лежащий вне всякого закрытого круга — терять было нечего).

**Починка проверена ПРЯМО, а не по намерению:** после пуша merge-ref пересобрался —
`refs/pull/413/merge` = `b849218a`, родители `970957c3` (текущий `main`) и `b36abc10`, блоб
`claude-review.yml` = `d7c5c84a`, **тождествен `main`**. Значит следующий круг гард пройдёт. Это
важнее аккуратности: проверка стоит одной команды, а её пропуск — доллара и такта.

## Почему запись едет своим PR

Исключение из правила «запись едет попутным диффом той работы, из которой родилась» (карточка роли),
и причина называется вслух: работа, из которой запись родилась, — это #413, а вся его доказательная
сила держится на посылке **«ровно один изменённый путь, `42 0`, разобранный YAML равен»**, записанной
в теле PR и перемеренной дверью. Второй путь в том же диффе эту посылку уничтожает — и уничтожает её
у PR, который стои́т под кнопкой john по гарду 4 с уже потраченным кругом ревью. Дифф этой записи
целиком журнальный, круга не требует (слово john 2026-09-11, тред `187`), и кнопка на нём — curator.

## Постскриптум приёмки: предел, записанный в ОДНОМ месте, оставляет обещание живым в другом

#413 сел в `main` коммитом `e55976b5a` (кнопка john, ~12:08Z). Приёмка автора перемерена на
`origin/main`, а не принята по докладу: блоб `notifier-watch.yml` тождествен блобу головы PR
(`8c46b3a6`), дифф squash — ровно один путь и `42 0`, `yaml.safe_load(e55976b5a^)` равен
`yaml.safe_load(e55976b5a)`, а единственная неканоническая строка вне комментариев — добавленный
пустой разделитель. Живой смотритель правку принял: GitHub исполняет прогоны
`Notifier Watch` на голове `e55976b5a` (`34842684330`, `success`, 12:18:10Z), то есть парсер
GitHub — не только `yaml.safe_load` — читает файл.

**И тут же нашлась дыра, которую сама эта приёмка и открыла.** Обещание смотрителя записано в
репозитории НЕ в одном месте: шапка воркфлоу — раз, таблица «Почтовые воркфлоу: все пять живых» в
корневом `README.md` — два, `docs/install-notes.md` §3а — три. Запись предела в шапке (ветвь Б
john) погасила безусловную формулировку ТОЛЬКО в шапке; строка README продолжала обещать «отказ
любого из четырёх уведомителей звонит письмом» без всякого «если», и читатель, который до шапки
воркфлоу не доходит, получал ровно то обещание, ложность которого тред и доказал.

**Правило, которое из этого следует:** записал предел обещания — **грепни само обещание**, а не
файл, который правишь. Место записи выбирает постановка, а число мест, где обещание повторено,
постановке неизвестно; здесь их оказалось три при одном названном. Дешевле всего это стоит в такте
ПРИЁМКИ своего же PR: дифф уже смёржен, критерий («где ещё сказано то, что я только что сузил»)
формулируется одной строкой грепа, и цена починки — один доковый PR, а не второй круг на том, что
стои́т под кнопкой человека.

Здесь погашено одно из двух оставшихся мест — строка README, зона `dev-core`. Второе названо
письмом этого треда и лежит в зоне curator: `docs/install-notes.md` §2, «С 2026-09-02 звонит —
смотритель разморожен тем же решением … и этот класс молчания закрыт не внимательностью, а
**событием**». Событие — это `workflow_run`, и предел треда говорит ровно про него: события мало,
нужен ещё поставленный на исполнение прогон. Своей рукой я туда не хожу — зона чужая, и перечень
мест отдан письмом, а не правкой.
