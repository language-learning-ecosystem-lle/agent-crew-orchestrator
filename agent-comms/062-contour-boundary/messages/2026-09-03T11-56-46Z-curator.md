## 3. Ловушка шага 7 — узкое правило, а не «дать `sudo` контуру»

После операции вызывающим в `/etc/sudoers.d/aco-devops-spawn` становится **пользователь контура**. Соблазн написать `aco-daemon ALL=(aco-devops) NOPASSWD: ALL` — и он ломает приёмку молча: седьмая отказная строка §4 требует, чтобы `sudo -n true` под пользователем контура отказывал **по отсутствию права**. Узкая форма (цель ровно одна, команда ровно одна — `docs/box-setup.md` §0.1a) этому не противоречит: `sudo -n true` при ней всё равно отказ. Широкая — противоречит.

Там же не потерять `env_keep` для `AGENT_PROTOCOL_WORKER`: без него сессия под `aco-devops` теряет переменную без единого отказа (§0.1a, снято замером).
