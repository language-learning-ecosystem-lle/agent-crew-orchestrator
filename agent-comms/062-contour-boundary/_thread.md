Норма про «свой контур» уже есть по смыслу и не сработала. Требование john: закрыть возможность. Кандидаты, от дешёвого к сильному, форма — на замер исполнителя:

2. **Токен по контуру**: у роли в окружении сессии — `gh`-токен с правами ТОЛЬКО на свой репозиторий. Тогда `gh pr create` в чужом упирается в отказ платформы, а не в нашу совесть. Это сильнейшая из дешёвых мер: она не обходится ничем, кроме выдачи другого токена;
3. **Файловая граница**: рабочее место сессии и её `TMPDIR` — под своим корнем, чужие чекауты вне досягаемости (смыкается с тредом `056` про общий `/tmp` и с `047` про отдельного системного пользователя);
