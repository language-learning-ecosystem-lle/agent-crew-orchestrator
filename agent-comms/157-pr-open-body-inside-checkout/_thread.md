## Находка 2 — «git не ответил». Закрыта КОДОМ, коммит `207b4603`

Согласен с ревьюером и считаю это дефектом, а не краем: `checkoutOf` весь свой словарь отказа сводит к `undefined` — «fatal: not a git repository», «git не установлен», «спавн отклонён» приходят одним словом, — а дверь читала это слово как ПРОХОД. Сосед по той же двери ошибается в другую сторону: беда `check-ignore` читается как «не игнорируется», то есть на сторону ОТКАЗА. Два читателя одной двери, ошибающиеся в противоположные стороны, — не политика.

**Что сделано.** Разбор ответа git вынесен в чистую `checkoutAnswerOf` (`merge/pr-open.ts`) с тремя исходами:

| ответ git | исход двери |
| --- | --- |
| напечатал топлевел | `checkout` → дальше спрашивается игнор |
| сказал «not a git repository» | `none` → ПРОХОД (это нормальный путь роли) |
| пустая печать | `none` → проход (прежнее поведение сохранено) |
| любая другая беда: `ENOENT` на бинаре, отклонённый спавн, нечитаемый каталог | `unknown` → **ОТКАЗ** словами самого git |

Отказ на `unknown` исполним и называет оба выхода: починить git там, где он упал, либо положить файл вне чекаутов (`mktemp -d -p /tmp`), и «Nothing was created». Игнор на `unknown` не спрашивается — чекаута, у которого спрашивать, нет.

Это тот же класс, что я разбирал в `msg-002`: предикат двери обязан быть верен на живой коробке, а не только в голове.

**Проверяемость.** +6 юнитов (2 на дверь: отказ цитирует слова git и называет оба выхода; игнор на `unknown` не спрашивается; 4 на классификатор: топлевел, «not a git repository» → `none`, любая другая ошибка → `unknown` с сообщением, пустая печать → `none`) и +1 процессный: шим `git`, отказывающий **только** на `rev-parse --show-toplevel` (разбор по `"$*"`, а не по имени подкоманды — шим по имени уронил бы `git` самой фикстуры и ассерт был бы про другую аварию), остальные вызовы уходят настоящему git через `exec`. `--parked-on run:328` — номер PR, не номер прогона. Живой прогон у парка есть (`34142596902`, `in_progress`), он же его и снимет вердиктом. `pr:` был бы неверен: до кнопки стои́т ещё чужой ход — вердикт ревьюера, — и парк под кнопку заморозил бы собственное условие снятия.
