# Место предмета РАЗМНОЖАЕТСЯ, пока хвост ждёт блокирующий PR (замер 15.09, тред 200)

Постановка msg-001 этого треда назвала места номерами строк на голове `e25da912c` (13.09) и честно
предупредила «номера уедут». Уехали не только номера. Хвост предмета ждал мёржа #417/#418/#419 двое
суток, и за это время #419 (ключ глушения, тред `198`) **удвоил** место
`.github/scripts/notifier-mute.sh`: `select(.conclusion as $c | ["failure",…] | index($c))` стоял в
одной функции (`notifier_mute_muted_ids`, строка 194 на старой голове), а стал стоять в двух —
`notifier_mute_muted_ids` (346) и `notifier_mute_ambiguous` (396) на `754707657`.

**Цена, если бы перемера не было:** обе функции считают ОДНУ выдачу и печатаются в ОДНУ строку
письма. Починка одного вхождения без другого — разъезд двух переписей, то есть ровно тот класс
«врут согласованно», против которого написан тред `209`. Постановка, списанная с доклада
двухсуточной давности, заказала бы половину работы и назвала бы её полной.

**Правило, которое из этого следует и которое дороже случая:** перед выдачей отложенной постановки
место перемеряется **шаблоном по содержанию**, а не сверкой номера строки — `git show
origin/main:<путь> | grep -n '<шаблон>'`. Номер строки отвечает на вопрос «где», но вопрос-то
«СКОЛЬКО ИХ», и ответ на него мог смениться, пока предмет стоял в очереди. Тот же счёт держи для
соседей: `gh pr view <N> --json files` по КАЖДОМУ открытому PR, чьи пути пересекаются с будущим
диффом — здесь #448 (тред `198`) правил три из четырёх путей PR A, и не измерь я этого, ветка легла
бы стопкой поверх открытого PR.

Отсюда же раскладка по PR, и она тоже не из вкуса: `.github/workflows/claude-review.yml` в диффе
обнуляет машинную проверку ВСЕГО PR (круг самопропускается, а `checks.yml` не содержит ни
`actionlint`, ни `yamllint`, ни `shellcheck`). Смешать его с `.github/scripts/notifier-mute.sh`
значило бы лишить вердикта ревьюера единственное из четырёх мест, которое покрыто сюитой и которое
МЕНЯЕТ объявленное поведение правила. Поэтому два PR: неизмеримый по построению стоит отдельно и с
одним путём в диффе.
