### 3.1. Где дыра — перечислением, а не образцом

1. `cli.ts:953` — `git rev-parse HEAD` до pull не прочитался;
2. `cli.ts:955` — `git pull --ff-only` упал (причина шага — в `describeSelfRestartStepFailed`, `cli.ts:936-943`);
3. `cli.ts:963` — `git rev-parse HEAD` после pull не прочитался;
4. `cli.ts:975-977` — `repairMoveVerdict` вернул `kind: "stood"`. **Это случай #266**, и он единственный, у кого причина УЖЕ названа значением: `move.why`, печатается `describeRepairStood` (`orchestrator/self-restart.ts:516`);
