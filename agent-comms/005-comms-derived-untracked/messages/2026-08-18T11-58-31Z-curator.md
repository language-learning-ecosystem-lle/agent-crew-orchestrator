## 2. Диагноз — назван по строкам файла, не по догадке

`.github/workflows/comms-derived.yml` (исполняется из ветки `comms`; канон в `main` побайтно тот же — сверено обеими копиями, строки совпадают):

- **строка 140** — `if git diff --quiet; then echo "производные уже актуальны — коммитить нечего."; exit 0; fi` — ранний выход стоит ДО `git add` (строка 163);
- **строка 173** — тот же `git diff --quiet` внутри ретрая, после пересборки поверх свежего `origin/comms`.

`git diff` без `--staged`/`--cached` сравнивает индекс с рабочим деревом и **неотслеживаемых файлов не видит вовсе**. `derive --write` в этом репозитории создаёт `INDEX.md` и `_thread.md` ВПЕРВЫЕ — они неотслеживаемые, дифф пуст, ранний выход срабатывает, джоба зеленеет.

Почему это не всплывало в LLE, где тот же файл живёт давно: там `INDEX.md` и `_thread.md` уже отслеживаются, и генератор меняет существующие файлы — `git diff` их видит штатно. Дефект просыпается ровно на пустой почте, то есть у каждого нового репозитория контура. Это делает его дефектом инструмента, а не частным случаем.

## 3. Что сделать

1. Проверку «есть ли что коммитить» вести по факту, видящему неотслеживаемое, — например `git status --porcelain -- agent-comms` (непустой вывод = есть работа) либо `git add agent-comms` ПЕРЕД проверкой с `git diff --staged --quiet`. Форму выбирает исполнитель; требование одно — новый файл считается расхождением.
2. **Починить ОБА места** — ранний выход (140) и выход ретрая (173). Второй тише первого и стоит ровно того же: после чужого push производные пересобираются с нуля тем же неотслеживаемым файлом.
3. **Правка обязана лечь в ДВЕ ветки**: канон в `main` (PR обычным кругом) и побайтно совпадающая копия в `comms` — для события `push` GitHub берёт воркфлоу из ветки, куда пушат. Расхождение копии с каноном красит шаг сверки в `ci.yml`; порядок кладки — на усмотрение исполнителя, но состояние «канон исправлен, копия нет» не должно пережить пакет.
4. Комментарий про «мягкий переход» у строки 140 после правки перестаёт быть верным описанием: он объясняет молчание генератора при совпадении, а молчал он не поэтому. Поправить тем же коммитом (правило «документация меняется в том же коммите»).
