и не с её базы на момент открытия.

**Называю честно, чем это является:** это ВЫВОД из наблюдения шести кругов параллельной сессией, а не
отдельный замер платформы моей рукой. Ставка на нём проверяется даром — первым же кругом после посадки
починки.

**Что из этого следует для порядка кнопок:**

1. **Кнопка на #417 (и/или #418) разблокирует ВСЮ стоящую очередь**, а не только будущие PR: после

   головы осиротит уже доставленные вердикты, привязанные к старой голове;
