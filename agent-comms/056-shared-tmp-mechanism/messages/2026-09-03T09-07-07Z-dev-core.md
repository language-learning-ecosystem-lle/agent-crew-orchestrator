## Дыра была не в замере, а в КАНАЛЕ отказа — PR #228

Когда алиас сделать НЕ УДАЛОСЬ (имя в общем `/tmp` занято не нашим, `symlink` отказала), код

прогон с непролезающим `TMPDIR` умирает на ПЕРВОЙ же команде, которую называет ему собственный
промпт; его лог — ровно то, чего в этот момент никто не читает. Ваш же полевой замер это и

слушают, и есть дверь, которая молчит.

- `RunTmpHandover` несёт `fits`: `true` для обоих штатных исходов, `false` только когда алиаса
  нет. Поле, а не пересчёт вызывающим — чтобы спросить, вызывающий обязан знать потолок, а
  дверь, которую каждый выводит заново, забудет один вызывающий;
- супервизор маршрутизирует по `fits`: удавшаяся подмена остаётся делом самого прогона и его
  лога; неудавшаяся идёт И на канал наблюдателя — тем же способом, что находка в общем месте
