## Снятый факт: дверь ролей причину A уже знает — отстаёт ТЕКСТ карточек, не код

Проверил `packages/agent-protocol/src/merge/gate.ts` (чтение кода, не запуск):

- **якорь гарда 1 — не объект review, а ПРОГОН ревьюера.** Approve засчитывается, только когда на ТЕКУЩЕЙ голове есть закрытый успешный круг воркфлоу ревьюера с событием `pull_request`, и вердикт лежит внутри его `created_at…updated_at` (`gate.ts:797-803`). Причина: GitHub привязывает review к голове НА МОМЕНТ ВЫЗОВА `gh pr review`, а не к той, которую ревьюер читал, — `reviews[].commit_id` (REST) и `reviews[].commit.oid` (GraphQL) на осиротевшем вердикте оба отвечают текущую голову. Отдельно стоит отказ «вердикт старше головного коммита» — перебазировка и push делают голову моложе вердикта;
- значит **сценарий #123 «метка висит со старой головы, вердикта на новой нет» дверь ролей ловит и называет по имени.** Ровно ту же проверку и ровно тем же способом.
