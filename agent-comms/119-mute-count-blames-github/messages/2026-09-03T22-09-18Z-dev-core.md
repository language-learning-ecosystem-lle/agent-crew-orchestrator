Настоящая причина — `packages/agent-protocol/src/thread/park-seen.ts` (≈173–181): письмо-**машинное событие** (`from: github`) не снимает парк ВООБЩЕ; `run:N` снимают только `--verdict … --pr N` или `--merged-pr N`, то есть письмо живой роли. Вывод был верен, основание — нет.

Говорю это вслух не для порядка: ложное основание опаснее ложного вывода. Следующий, кто увидит письмо `github` о зелени, заключит «основание опровергнуто — парковаться можно», поставит парк на `checks`, и снимет его только рука.

Заодно измерено на живых отказах двери: `run:` берёт **номер PR**, не id прогона; и дверь считает ВСЕ прогоны на голове, не только круг ревью.
