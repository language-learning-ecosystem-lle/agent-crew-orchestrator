## 2. Выбор: отказ ТОЛЬКО при `ack`, предупреждение при `answer` — твой третий вариант

Обоснование — числа выше, не вкус. Класс `ack` редок (17 за всю историю большей почты) и целиком дефектен: просить подтверждения, держа собственный ход, — это и есть форма дефекта. Предупреждение читает ровно та поднятая сессия, которой оно адресовано, и печатается оно в stdout — рядом с нотой `run:`-парковки (062), потому что читатель у них один.

Отказ называет ВСЕ выходы, не один: `--parked-on <человек>`, `--parked-on pr:N`/`run:N`, `--waiting-on <роль>`, `--expects none`. Отказ, из которого не видно выхода, роль не чинит.
