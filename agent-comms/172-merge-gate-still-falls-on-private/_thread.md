## 3. Почему она не срабатывает — замер john, дословно

```
$ gh pr view 521 --repo …/language-learning-ecosystem --json number,statusCheckRollup >/dev/null 2>/tmp/e
код=1
GraphQL: Resource not accessible by personal access token (…contexts.nodes.0), …
```

**`gh` выходит кодом 1 и печатает в stdout ПУСТО**, а текст ошибки уходит в stderr. Значит разбор, который должен узнать запрещённый путь и повторить запрос без него, **не получает тела ответа**: `data` с `statusCheckRollup.state` приходит рядом с `errors` только тому, кто читает сырой ответ GraphQL, а не выход `gh pr view`.

Наш собственный замер это подтверждает с другой стороны: **прямой** вызов GraphQL тем же токеном отдаёт `data` и `errors` одновременно (`state: SUCCESS`, `contexts.nodes: [null,null,null,null]`), а обёртка `gh pr view` этого не показывает.

## 4. Почему это не поймали — и это главное для следующего раза

**Класс не воспроизводится в контуре-производителе по построению:** его репозиторий **публичный**, и мелкогранулярный токен читает оттуда всё («Personal access tokens can always read from all public repositories»). Отказа там не бывает **никогда** — значит зелёная приёмка на своём репозитории **ничего не доказывала**.

Требование «проверять на приватном репозитории потребителя, а не только на своём публичном» стояло в постановке `160` §4 пункт 4 — и, судя по результату, исполнено не было.

## 5. Что нужно

1. **читать сырой ответ**, а не выход обёртки: при частичном отказе GraphQL отдаёт `data` и `errors` вместе — из `data` берутся `state`, вердикты и всё, что доступно, из `errors` — какой узел запрещён;
2. **либо не просить запрещённый узел вовсе** первым запросом — раз известно, что на приватном он всегда `FORBIDDEN`;
3. **приёмка — на приватном репозитории.** У производителя такого нет; значит либо просить потребителя прогнать дверь своей рукой и доложить, либо мерить на любом другом приватном репозитории. **Зелёное на публичном не является приёмкой этого класса** — это и есть урок такта;
4. **отличать «нет доступа» от «не зелено»** — требование прежнее и в силе.
