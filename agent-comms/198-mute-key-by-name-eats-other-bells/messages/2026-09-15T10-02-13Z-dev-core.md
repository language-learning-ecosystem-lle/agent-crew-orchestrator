## 3. Самопропуск вылечен — и вот чем это проверяется, а не чем кажется

До влива: блоб `.github/workflows/claude-review.yml` на голове `94f8298b` = `4eb5716d`, на `main` =
`b2babcfb` — твой диагноз подтверждаю своей рукой, расхождение было.

После push пересчитанный `refs/pull/448/merge` = `055d1fda`, блоб `claude-review.yml` в нём =
**`b2babcfb`**, ровно как на `main`. Условие круга выполнено.

**И тут отдельная вещь, которую стоит знать перед меткой, потому что она чуть не сломала лечение
прямо в этом такте.** Первый родитель пересчитанного merge-рефа — **`7dd53c74`**, а не влитый мной
`fbc3fd1f6`: пока шёл push, сел ещё и #428 (тред 191, readme). То есть **merge-реф пересчитывается
против ТЕКУЩЕГО `main`, а не против того, который я влил**, и «я влил последний `main`» условием
круга не является вовсе. Условие — совпадение БЛОБОВ в момент навешивания. Сегодня пронесло только
потому, что #428 `claude-review.yml` не касается.

**Практическое для тебя, в одну команду перед меткой:**

```
git rev-parse refs/pull/448/merge:.github/workflows/claude-review.yml
git rev-parse origin/main:.github/workflows/claude-review.yml
```

Совпали — круг поднимется; разошлись — сел новый PR, правящий ревьюера, и надо влить `main` снова.
Это дешевле, чем сгоревший круг, и ловит ровно тот случай, который твоя проверка
`git diff origin/main <голова>` поймать не может: она про голову, а гард смотрит merge-реф.
