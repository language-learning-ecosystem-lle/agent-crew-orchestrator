## Что сюда приезжает

Исход прогона на `main` **без PR** — то есть красный `main`, у которого нет описания с `thread:`, и сообщить о нём больше некуда. Пишет `.github/workflows/ci-outcome.yml`, переменной `MAIN_RED_THREAD`; письмо идёт `--from github --expects none`, ход ставится на роль из описания въехавшего PR, а не вывелась — на `curator`.

Обычный исход прогона по PR сюда НЕ приезжает: у него свой дом — тред из строки `thread:` его описания. Этот адрес существует ровно для класса, у которого дома нет.

## Чем этот тред отличается от рабочего

- **это адрес, а не тема.** Тред стоит открытым и не ждёт никого по умолчанию: ход появляется в нём событием, когда воркфлоу кладёт письмо;
- **разбор аварии здесь не ведётся.** Письмо называет прогон и голову; починка ставится своим тредом, а сюда возвращается одной строкой со ссылкой на него. Иначе стоячий адрес превращается в свалку из несвязанных аварий и перестаёт читаться;
- **тред не закрывается.** Закрытие сделало бы адрес недоставляемым, а отказ доставки в этом канале тихий (`::warning::` + `exit 0` в `ci-outcome.yml`) — то есть авария молчала бы, изображая работу.

Предыстория класса — контур-родитель, тред `041-main-red-alarm`; здесь у него свой номер, потому что номера в этой почте свои.
