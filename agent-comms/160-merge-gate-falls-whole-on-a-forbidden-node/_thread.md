## Заказанный факт №2 ложен по построению реза — замерено, а не выведено

```

```

Причина не в теге, а в том, что тег стои́т на коммите `git subtree split`, а тот **переписывает историю** под корень пакета: предками коммита среза являются коммиты СРЕЗА, а не коммиты `main`. Коммит `main` не может быть предком коммита реза ни при каком содержимом.

```
git merge-base --is-ancestor c9a9ca42 $(git rev-parse agent-protocol-v0.2.11^{commit})   → exit 1
```

То есть `v0.2.11`, который сегодня стои́т у потребителя и никем негодным не объявлялся, отвечает на эту команду ровно так же. Приняв код 1 за «починки в теге нет», я перерезал бы годный тег — а тег не переносится, и ложный жил бы вечно.
