## Что легло

**П-1.** `runWorkspaceInstall` больше не знает имени инструмента как строки спавна: он принимает уже разрешённый `ResolvedTool`, а резолвит его тот же `resolveTool` из `orchestrator/tool-path.ts` (второго механизма не заведено). Имя названо один раз константой `WORKSPACE_INSTALL_TOOL`.

**П-2.** Премисса печатается ДО команды — `levelling — <нота двери>, running '<путь>' (beside this node binary)`, ровно форма шагов рестарта. Разбор конца спавна вынесен в новый чистый стык `workspaceInstallOutcome` (`workspace-install.ts`): это позволило померить ВЫБОР сентенции без диска. Прежнее `pnpm did not run — spawnSync pnpm ENOENT` не называло ни одного просмотренного места и читалось как сломанный проект; теперь — `NO PROCESS RAN — there is no executable 'pnpm' to start (ENOENT…). Looked beside this node binary first, then on PATH: …` против `'<путь>' ran and exited <n>: <его вывод>`.

**П-3, и это главная работа диффа.** Перехват стенда переехал туда, куда смотрит резолюция. Каталог стенда держит записывающий `pnpm`, СИМЛИНК `node` на настоящий бинарь и преднагружаемый модуль, ставящий `process.execPath` на этот симлинк (`NODE_OPTIONS=--import …`; свойство `process.execPath` записываемое). Симлинк нужен потому, что CLI спавнит `process.execPath` для фонового ребёнка, а именно ребёнок выравнивает дерево в случаях `--detach`. Подделана РОВНО одна вещь — местожительство интерпретатора, то есть тот самый факт, который стенд воспроизводит: ящик, где менеджер пакетов лежит рядом с node. **Герметичность не ослаблена ни в одном из 16 случаев** — ни копии `node` (118 МБ на файл), ни хардлинка (на этом ящике `ln: Operation not permitted`), ни настоящей установки. И `PATH` прогона теперь `<node>:/usr/bin:/bin`, `pnpm` на нём нет ВОВСЕ — то есть всякая записанная стендом установка есть вызов, которого среда сделать не могла.

**П-4. Ещё одна точка того же критерия нашлась и взята сюда же:** `capability run` с правом `repo-refresh` (`git pull --ff-only` + `pnpm install` в названном чекауте) — её несёт поднятая демоном сессия, среда та же. Спавн резолвится; **объявленный глагол не тронут** — след `capabilities.log` и все отказы печатают команду так, как её объявляет карточка, иначе читатель перестал бы сверять след с карточкой. `git`/`gh`/`du`/`id`/`ssh` под критерий не попадают (есть в системных каталогах) — оставлены как есть.
