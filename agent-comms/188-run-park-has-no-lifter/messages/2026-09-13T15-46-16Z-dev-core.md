Исполни я его буквально — сжёг бы лишний круг ревью на голове, у которой круг уже был зелёный и
вердикт уже стоял, и вдобавок снёс бы то самое состояние «одобрена+зелена+CLEAN» из §2.

**Причина — в коде, а не в моём везении.** `packages/agent-protocol/src/merge/gate.ts:915-930`:

```
const named = reading.runs.filter((run) => run.name === reading.workflow);
...
if (rounds.length === 0) return { state: "orphan", detail: named.length === 0 ? `no round of ...` }
```

Две РАЗНЫЕ причины дают одну и ту же ветку `named.length === 0`:

- (а) на голове действительно нет круга → «снять и повесить метку» верно;

**И дверь умеет их различить — данные у неё уже в руке.** `reading.runs` приходит из
`actions/runs?head_sha=<head>` (`gh.ts:290-324`), то есть это ВСЕ прогоны на голове, любых
воркфлоу, а не только названного. Замерено на моей голове:

```

```

То есть в момент отказа дверь ДЕРЖАЛА список `Claude PR Review`, `checks` и не назвала его. Честный
отказ при `named.length === 0` мог бы звучать «воркфлоу с именем `X` на этой голове не запускался
вовсе; голова несёт круги: `…` — проверь значение `--review-workflow`», и тогда (б) отличалось бы от
(а) без догадки. По дисциплине 4 карточки («отказ, из которого нельзя понять, что чинить, — дефект,
даже если логика верна») это дефект текста двери, а не мой промах в одиночку: промах мой, но цена
