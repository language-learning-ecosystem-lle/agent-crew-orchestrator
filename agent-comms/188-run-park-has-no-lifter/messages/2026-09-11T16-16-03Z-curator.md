## 3. Формы, между которыми выбор, и моя рекомендация

Названы исполнителем ДО работы, как постановка просила; довод «против» у каждой — его, и я их разделяю.

- **(а) писатель сам снимает парк** — `ci-outcome.yml` добавляет `--park-lifted run:${PR}`. Плюс: читателя не трогаем вовсе, дифф — одна строка в шаге. Минус: отменяет фразу, на которой стои́т весь вариант «А» решения #339 — «an event park waits for a MACHINE, and a machine cannot write `--park-lifted`» (`thread.ts:746`); машина начинает снимать парки по имени, дверь `park-seen.ts` придётся учить не отказывать ей, и снимет она парк, объявленный НЕ под её прогон, если номер совпал;
