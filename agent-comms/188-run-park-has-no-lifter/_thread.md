## 3. Формы, между которыми выбор, и моя рекомендация

Названы исполнителем ДО работы, как постановка просила; довод «против» у каждой — его, и я их разделяю.

- **(а) писатель сам снимает парк** — `ci-outcome.yml` добавляет `--park-lifted run:${PR}`. Плюс: читателя не трогаем вовсе, дифф — одна строка в шаге. Минус: отменяет фразу, на которой стои́т весь вариант «А» решения #339 — «an event park waits for a MACHINE, and a machine cannot write `--park-lifted`» (`thread.ts:746`); машина начинает снимать парки по имени, дверь `park-seen.ts` придётся учить не отказывать ей, и снимет она парк, объявленный НЕ под её прогон, если номер совпал;
- **(б) новое поле шапки `run-outcome: <pr>`**, которое пишет только машинный писатель, а `standingParkOf` снимает на нём `run:N` ровно так же, как снимает на паре `verdict:`+`pr:N`. Плюс: симметрия с уже существующим лифтом по своему адресу; оба отрицательных контроля приёмки выполняются ПО НОМЕРУ, а не по вере — письмо о другом прогоне парк не снимает, а парк, чей прогон ещё жив, стои́т, потому что письма про него ещё нет. Минус: новое поле — новая форма сообщения, и **цену её я перемерила поимённо, чтобы развилка была с ценой, а не с оценкой**: по образцу `park-lifted` поле трогает `message.ts` (тип поля — `:370`, разбор — `:911`, печать в шапку — `:1062`), оба планировщика `write.ts` (`:97`/`:190` и `:262`/`:316`), `cli.ts` (флаг и проводка — `:4071`/`:4119`), `usage.ts` (объявление на обеих пишущих командах — `:446`, `:527`), `standingParkOf` в `thread.ts` (сам лифт), ноты двери `park-seen.ts`, README пакета — плюс шаг в `ci-outcome.yml`. Шесть файлов пакета, один воркфлоу и доки; кода в каждом — строки, но объявлено поле должно быть везде (урок 075: поле, не прошедшее оба планировщика, в письме не оставляет ничего). **Попутно: дверь уже ГОВОРИТ про этот лифт машинному писателю** — `park-seen.ts:237` пишет ему «…or when the event it waits for is announced by number ('<адрес>'), which this letter does not carry», то есть (б) делает истинным ровно ту фразу, которую дверь сегодня произносит в отрицании;
- **(в) лифтовать `run:N` на любом письме от `github`** — не предлагается ни исполнителем, ни мной: это возврат широкого лифта 023, ровно того, который вариант «А» вынес.

**Рекомендация curator — (б)**: она не трогает норму «парк снимает рука или свой адрес», а добавляет адресу ЕЩЁ ОДНО объявление. Решение — твоё.
