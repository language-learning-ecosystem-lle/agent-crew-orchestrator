## Постановка: все воркфлоу этого репозитория переводятся с self-hosted пула на `ubuntu-latest`

**Мотив, измеренный сегодня**: после перевода репозитория в public (12:20Z) джоба `checks` PR #10 простояла в очереди **77 минут** (15:01:57Z → 16:18:56Z) — раннер-группа организации по умолчанию не обслуживает публичные репозитории. John временно включил «Allow public repositories» (16:18Z, очередь ожила), но целевое решение — hosted:

1. **Изоляция**: публичный репозиторий на self-hosted железе = потенциально чужой код (fork-PR) на ящике рядом с LLE-контуром и секретами; GitHub прямо не рекомендует self-hosted для public. Hosted снимает класс риска целиком;
2. **Деньги**: для public-репозиториев GitHub-hosted раннеры бесплатны без лимита минут;
3. **Смысл**: CI generic-пакета на голой ubuntu доказывает установку «у чужого» — ровно то, чем пакет теперь является.

## Скоуп

- `runs-on: [self-hosted, linux, x64]` → `ubuntu-latest` во ВСЕХ живых воркфлоу репозитория (`checks.yml`, `comms-derived.yml`, `merge-notify.yml`, `notifier-watch.yml`; замороженные — по месту, замер исполнителя). Симметрично откатывает #2 — тот делался на приватном репозитории, публичность легитимно меняет ответ;
- проверить пригодность окружения: node/pnpm ставятся шагами (setup-node), кэш pnpm store через actions/cache — замер исполнителя, что уже есть в воркфлоу, а чего не хватает;
- **особое внимание process-тестам** (спавны демонов, тайминги): hosted-железо слабее netcup (шареные 4 vCPU) — если флак проснётся, таймауты калибруются по месту, НЕ ослаблением утверждений;
- `comms`-копия `comms-derived.yml` — той же волной, побайтово (иначе шаг сверки красный);
- после merge: john выключает «Allow public repositories» на группе Default обратно (галка была временной — сказать ему в отчёте явным пунктом).
