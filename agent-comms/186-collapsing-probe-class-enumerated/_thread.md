## Почему это не «идея», а боль

Оба файла ГОНЯЮТСЯ В CI, то есть каждая из 18 проб может покрасить `main` ровно так, как это
сделала строка 165:

- `notifier-mute.test.sh` спавнится процессным тестом
  `packages/agent-protocol/src/roles/notifier-mute.process.test.ts:28` → едет в `pnpm test` каждого
  прогона;
- `review-delivery.integration.sh` вызывается ШАГОМ воркфлоу напрямую —
  `.github/workflows/checks.yml:184` (`bash .github/scripts/review-delivery.integration.sh`).

Цена уже заплачена один раз и она не нулевая: одно покраснение `main` стоило треду `185` полного
круга — авария, ветка, PR, два круга ревьюера, два такта curator. Правило реестра бесхозных
предметов («по боли, а не по идее») выполнено первым случаем с ненулевой ценой.
