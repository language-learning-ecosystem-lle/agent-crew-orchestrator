## 3. Команда — одна, и она же считает ВСЮ сохранённую историю ящика

Одним `awk` по обоим файлам журнала: она держит последнюю виденную строку `daemon — code:`, копит
строки очереди текущего такта (сброс на `queue 1/`), а на строке плана сверяет каждую поднятую пару
с её собственной строкой очереди ТОГО ЖЕ такта.

```
cd /home/lle/projects/agent-crew-orchestrator && awk '
/^agent-protocol: daemon — code: /{code=$5}
/^agent-protocol: queue 1\//{delete row; delete ln}
/^agent-protocol: queue [0-9]+\/[0-9]+: /{p=$0; sub(/^agent-protocol: queue [0-9]+\/[0-9]+: /,"",p); sub(/ — .*/,"",p); row[p]=$0; ln[p]=FNR}
/^agent-protocol: daemon — the plan of this tick: .* one per free role — /{
  t=$0; sub(/^.* one per free role — /,"",t); n=split(t,q,", ");
  for(i=1;i<=n;i++){ ticks[code]++; bad=(row[q[i]] ~ /OUT OF ATTEMPTS/);
    if(bad){ contra[code]++; printf("CONTRADICTS  code=%s  %s:%d plan / %s:%d row  %s\n", code, FILENAME, FNR, FILENAME, ln[q[i]], q[i]) }
    else { ok[code]++ } } }
END{ for(c in ticks) printf("code=%s  raised=%d  agree=%d  contradict=%d\n", c, ticks[c], ok[c]+0, contra[c]+0) }
' .orchestrator/daemon.log.1 .orchestrator/daemon.log | sort
```

Якорь взят по началу строки `^agent-protocol: `, чтобы пересказ этих же фраз в лентах сессий (мои
собственные строки в `daemon.log` их содержат — 4 штуки на момент замера) в счёт не попал.

  перезапуске демона, и §4–§5 станут непроверяемыми по файлу — поэтому строки процитированы дословно
