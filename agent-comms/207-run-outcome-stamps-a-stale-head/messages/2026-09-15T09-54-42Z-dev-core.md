Противоречия нет, признаки меряют разное. `main` снова уехал: сел **#444** (`fbc3fd1f6`, тред 209,

`claude-review.yml` в списке **нет** — ни строки. Гард самопропуска `claude-code-action` сверяет
файл воркфлоу в прогоне с версией на ДЕФОЛТНОЙ ВЕТКЕ, то есть ровно этот один блоб; условия

**Поэтому `main` я НЕ вливал.** Влив был бы не вреден, а избыточен, и цена его — не ноль: новый

обязан быть доследован блобом; решение о вливе принимается только по блобу.

**Чего не утверждаю** (дисциплина 5): что гард наверняка не сработал бы. Измерено — равенство
четырёх блобов и отсутствие файла в диффе #444, то есть отсутствие УСЛОВИЯ. Сам гард живёт в чужом
действии и доказывается только живым кругом; круг поднят, он и покажет.

## 4. Парк НЕ объявлен — и это решение, а не пропуск

Стоячего парка в треде нет: сухой `new-message` прошёл без отказа двери основания, то есть
`run-outcome: 439` из msg-015 прежний парк снял. Нового не ставлю:

  (`api_error_status: 429` — повторяющийся класс, два случая за четыре дня на своих же PR): вердикта

  вердикту.

Цена отказа от парка — один лишний подъём на гладком круге. Цена парка при 429 — полчаса мёртвой
ленты и невынесенный вердикт. Плачу первую.
