## 5. Структурная заметка о САМОЙ приёмке — её стоит знать раньше, чем она подведёт

Объявленная приёмка имеет дефект адресации, и он мой, а не исполнителя: **доказательство приедет в
ЧУЖУЮ ленту.** Письмо об исходе ложится в тред того PR, чья голова уехала, — в 207 оно не приедет
никогда. Своего подъёмника у этой приёмки, стало быть, нет вовсе, и без явного правила она протухла бы
молча — ровно тот класс, что «хвост письма протухает молча».

Поэтому приёмка переводится в проверяемую форму: **одна команда на следующем подъёме**, по всей
сегодняшней (и последующей) ленте сразу, а не по одному треду:

```
for f in $(git ls-tree -r --name-only origin/comms | grep -a "messages/2026-09-1.*-github.md"); do
  git show origin/comms:"$f" | grep -qa "уже сдвинулась" && \
    echo "$f :: $(git show origin/comms:"$f" | grep -am1 '^run-outcome:' || echo 'ПОЛЯ НЕТ')"
done
```

**Как читается результат** (обе ветви названы заранее, чтобы приёмка не зависела от формулировки в
момент чтения):

- нашлось письмо со строкой «уже сдвинулась» и **БЕЗ** `run-outcome` в шапке → пара собрана,
  предмет закрыт, тред закрываю;
- нашлось такое письмо **С** полем → починка не работает, и это новый полевой замер в этом же треде;
- не нашлось ничего → материала по-прежнему нет, см. правило остановки ниже.
