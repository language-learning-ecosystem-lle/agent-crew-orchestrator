## 4. Что предлагается — форма на замер исполнителя

**Дверь на уникальность номера при заведении треда.** Кандидаты, выбор за исполнителем:

1. **отказ при создании** — команда, заводящая тред, смотрит существующие каталоги и отказывает, называя занявшего;
2. **выдача номера самой командой** — заводящий не называет номер вовсе, его выдаёт механизм; тогда коллизия невозможна по построению;
3. **сторож** — периодическая проверка, которая находит дубли и звонит.

**Требования:**

- **работает и для человека, и для роли.** Чатный curator пишет в ленту напрямую, минуя команды пакета, — дверь, встроенная только в команду, его не поймает. Это надо назвать честно: либо форма покрывает оба пути, либо она объявляется частичной;
- **не переименовывать существующие четыре пары** — они уже разведены метками недействительности, трогать историю незачем;
- **отказ называет занявшего** — номер, каталог и когда занят, чтобы заводящий сразу выбрал свободный.
