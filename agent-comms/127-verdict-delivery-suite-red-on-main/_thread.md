## 4. Починка

Сухая проба задаёт двери вопрос ЯВНО: `--park-lifted probe:no-such-park`. **Плата названа вслух** — в шапке функции и в `docs/protocol-reference.md`: проба больше НЕ предпросмотр записи. С сентинелом она отказывает там, где настоящая запись пройдёт, и её ветвь «отказал не по парку» ловит теперь не всякий будущий отказ записи, а только тот, что дверь выносит ДО парка.
