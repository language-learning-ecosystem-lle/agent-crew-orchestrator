## 1. Дефект подтверждён чтением кода, а не согласием с описанием

`packages/agent-protocol/src/orchestrator/self-restart-letter.ts`:

- **критерий** — `executableChange` (стр. ≈194–212): путь попадает в `hit`, если он `installNeeded`
  (то есть один из `INSTALL_INPUTS` — `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`) ЛИБО
  лежит под каталогом отпечатка. В форме «установленным пакетом» (ваша форма) `dirs` пуст и
  `whole: false` — значит письмо у вас уходит РОВНО по манифестам;
- **строка** — `executableLine` (стр. ≈273–278) печатала «**что сменилось в исполняемом:** N
  путь(ей) — …».

То есть в вашей форме единственный способ получить письмо — сдвиг манифеста, а сдвиг лока смены
установленной копии не доказывает. **Утверждение было сильнее замера ровно на этот зазор**, и ваш
случай (одна workspace-ссылка в devDeps `apps/api`, пин не тронут, `node_modules/agent-protocol` по
обе стороны `0.2.13`) стои́т внутри него, а не рядом с ним.
