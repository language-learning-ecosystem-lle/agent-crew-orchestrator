## 1. Где сессия узнаёт факт: ПРОМПТ, а не отказ двери

Постановка оставила выбор поверхности исполнителю. Выбран **промпт подъёма** (плюс строка запуска
`dependencies — …`, которую читает человек), и отказ двери отвергнут по измеримому доводу: **пустое
дерево — НОРМАЛЬНОЕ состояние места, созданного мгновение назад.** С ключом по паре (#366) такое
дерево родится на каждый новый тред, то есть дверь-отказ отказывала бы собственному контуру на
большинстве подъёмов. Сессии не хватает не разрешения, а ФАКТА — факт и едет ей, до первой команды.

Текст, который она получает (дословная форма):

```
THE DEPENDENCIES OF YOUR WORKING TREE ARE NOT INSTALLED — '<дерево>/node_modules',
'<дерево>/packages/agent-protocol/node_modules' are not there, while the home checkout
'<чекаут>' has an install in each of them. This tree was made for the run '<роль>' a moment
ago and nothing installs into it. Every command of this package started from here —
INCLUDING the mail commands above — dies on 'ERR_MODULE_NOT_FOUND' before it does anything,
and the error names a package rather than this fact. Run this once, before your first
command: `pnpm --dir <дерево> install --frozen-lockfile`
```

Три вещи в нём сделаны намеренно:

- **названа ошибка, которую сессия иначе встретит** (`ERR_MODULE_NOT_FOUND`): заметка обязана
  опознаваться по падению, которое она предотвращает, а не только по состоянию, которое описывает;
- **строка починки ОДНА и в форме `--dir`** — она верна и из дерева (cwd сессии), и из любого
  другого места (журнал читают не оттуда). Это та же форма, что печатает отказ двери версии треда
  `085`: в контуре должна быть одна строка для грепа, а не две;
- **заметка едет и в РЕЗЮМЕ-промпт.** Резюме обещает «рабочий каталог ровно такой, каким ты его
  оставил», а прогон, оборванный ДО установки, оставил именно нерабочее дерево — это состояние
  резюме и наследует.

## 2. Почему это ВТОРАЯ проверка, а не удлинение двери треда 085

`workspace-package.ts` сравнивает установленную КОПИЮ `agent-protocol` в дереве роли с копией в
домашнем чекауте. В контуре, где пакет и ЕСТЬ репозиторий, такой копии нет ни там, ни там — сравнивать
не с чем, и молчание там ВЕРНО (это его собственный тест). Отсутствуют здесь не копии пакета, а его
СОБСТВЕННЫЕ зависимости, живущие в раскладке pnpm рядом с ним. Другой факт, другой читатель — новый
модуль `workspace-dependencies.ts`.

**Меряются два диска, а не раскладка менеджера пакетов.** Критерий «есть ли `node_modules`» пришлось
бы знать про раскладку и он был бы неверен для следующего контура. Сравниваются каталоги, в которых
установка ЕСТЬ у ДОМАШНЕГО ЧЕКАУТА (обход на два уровня — мимо точка-каталогов, мимо самого
`node_modules` и мимо всего, что несёт свой `.git`), против тех же относительных каталогов в дереве
роли. Домашний чекаут — то дерево, из которого демон грузит СВОИ модули, то есть единственное место,
где «установлено» — факт, а не ожидание. Это тот же ход, что делает дверь версии с версиями, заданный
на уровень ниже.

**Пропуск каталогов с собственным `.git` — не удобство, а необходимость этого контура:** деревья ролей
висят ВНУТРИ репозитория, и без пропуска домашний чекаут отрапортовал бы дерево каждой чужой роли как
корень установки, которого «не хватает» рабочему месту.

## 3. Приёмка постановки — по пунктам

1. **дерево пары без установки → сессия получает имя факта и одну строку починки** — процессный тест
   через настоящий подъём, промпт вынут из argv стенда (не из наших намерений). Отдельным случаем
   покрыто, что путь в строке починки — путь дерева ПАРЫ, а не роли (177 × 161): строка,
   указывающая в чужой каталог, ставит зависимости никому;
2. **здоровое дерево лишнего слова не получает** — отдельный тест: ни строки запуска, ни фразы в
   промпте. Плюс ещё один отдельный: контур, у которого установки нет НИГДЕ, тоже молчит — требование,
   выведенное из пустого замера, было бы ложной фразой в каждом промпте такого контура;
3. **`pnpm install` из процесса демона в чужое дерево НЕ появляется.** Решение john треда `085` §4
   стоит нетронутым; в диффе нет ни одного запуска менеджера пакетов, и работа к john не поехала,
   потому что выбранная форма его не потребовала.
