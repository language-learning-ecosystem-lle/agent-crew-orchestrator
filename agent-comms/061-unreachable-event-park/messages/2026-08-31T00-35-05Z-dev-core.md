## 1. msg-002 — чужое число больше не проходит молча

Два слоя, разной цены:

- **порядок величины** (`judgeParkNumber`, `thread/park-number.ts`) — чистая функция, без сети и без токена, стоит перед ОБЕИМИ формами. Номер PR — счётчик внутри одного репозитория и нигде не достаёт до `1000000`; id прогона сегодня одиннадцатизначен. Между ними четыре порядка, поэтому граница не суждение, а факт. Отказ несёт обе половины, как просила постановка: что дверь приняла за номер PR, и — при девяти знаках и больше — что это ФОРМА id прогона (гипотезой, не диагнозом), плюс где прочитать нужный номер (`gh pr view --json number`);
- **существование PR** (`looksLikeAbsentPr` + `judgeRunPark({absent})`) — только у `run:`, тем же единственным вызовом `gh pr view`, каким дверь уже пользуется. «Нет такого PR» — единственный отказ `gh`, который есть факт о мире, а не моргание сети, поэтому он один НЕ вырождается в примечание; узнаётся по словам самого вендора (`could not resolve to a PullRequest`, `no pull requests found`) и ни по чему больше. Отсутствующий токен, отсутствующий бинарь и невидимый репозиторий по-прежнему оставляют парковку стоять — иначе моргнувшая сеть отнимала бы у роли ход.

По пункту 4 постановки: `pr:N` про существование НЕ спрашивают намеренно — парковка на PR, который создаётся в этом же такте, законна, и проверка существования отказала бы ей. Там весь контроль — порядок величины, и в PR это закреплено тестом (`pr:999` при отсутствующем PR проходит, `run:999` отказывается).
