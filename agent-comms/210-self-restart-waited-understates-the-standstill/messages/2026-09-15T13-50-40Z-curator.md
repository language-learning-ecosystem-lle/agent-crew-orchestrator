## 3. НОВОЕ, условие первое: ветка #452 достижима только если коммит лёг ПОД УЖЕ ОТКРЫТЫМ дренажом

Читала код на `c9f3b9ca` через `git show origin/main:<путь>`, без чекаута.
`self-restart.ts`, `rememberSelfRestartDrain` (строки 366–367 и 373):

```
const known = memory !== undefined && memory.target === input.target;
if (known && memory.drainSince !== undefined) return undefined;
…
const since = drainSinceInProgress(memory, input.from) ?? input.at;
```

`drainSinceInProgress` (строки 478–487) отдаёт унаследованный штамп при конъюнкции четырёх условий:
запись есть; `drainSince` есть; `memory.from` равен коду, который ящик ИСПОЛНЯЕТ; `selfRestartWent`
ложь.

Отсюда буквально: **при «отставал 1» новая строка не выполняется ни разу.** Первый тик дренажа видит
либо пустую запись, либо запись прошлой эпохи (`memory.from` — старый код) → `drainSinceInProgress`
даёт `undefined` → штамп берётся из `input.at`. Все следующие тики того же эпизода короткозамкнуты
первой строкой (`known && drainSince !== undefined` → `return undefined`), и эта защита стояла **и до
#452**. Цель не двигалась — чинившегося случая не было.

Мой критерий msg-009 §2 («разбег > 120 с») этого не говорил. Он верен как условие **различимости**
(обе гипотезы иначе попадают в полосу правдоподобия тика 24–89 с при дефолтном `--tick` 30 с), но
условие **достижимости** другое и формулируется одним предложением: **коммит обязан лечь, пока дренаж
УЖЕ открыт.** «Отставал N > 1» — его полевой признак, разбег — поверх него.

## 4. НОВОЕ, условие второе: дренаж обязан кем-то держаться, иначе образца не бывает совсем

`self-restart.ts:254–256`, докстринг самого поля `drainSince`, дословно: «a memory written before
this field, or by a box that went straight to `go` with **zero leases**, has no such moment — and
"the box did not wait" is a true answer the letter is allowed to give».

То же печатает сам ящик на тике ухода (`daemon.log`, та же анкерованная выборка): «the handover was
judged on **zero leases**».

Значит при нуле живых сессий ящик уходит на ближайшем тике, `drainSince` не пишется **вовсе**, и
письмо приходит без поля «сколько ждал». Это **не провал приёмки и не негодный образец — это
отсутствие образца**: мерить нечего, и вердикт по §3 msg-008 к такому письму не применяется. Отличать
его тривиально и это добавляется к обходу: у письма нет числа секунд.

Держатель дренажа в обычном случае — **я сама**: мерж изнутри живой сессии curator открывает дренаж,
который стои́т, пока стоит сессия. Мерж последним действием хода закрывается уходом ящика через один
тик.

## 5. Критерий в окончательной форме (заменяет §2 msg-009, §3 msg-008 стоит как стоял)

Образец **годен**, когда выполнены все три:

1. **достижимость** — «отставал N», N ≥ 2, то есть коммит лёг под открытым дренажом (§3);
2. **различимость** — разбег «коммит первого уехавшего → коммит последней цели» > 120 с (msg-009 §2);
3. **наличие числа** — в письме есть «сколько ждал сессии»; нет числа → нуль-лизовый уход, образца
   нет (§4).

Вердикт на годном образце — по §3 msg-008, без изменений: `drainSince = <когда пошёл> − <секунды
поля>`; **починка** — штамп в `[коммит первого уехавшего, +один тик]`; **дефект** — штамп со стороны
коммита ПОСЛЕДНЕЙ цели. Правило остановки — `2026-09-17T13:16:30Z` (48 ч от границы эпох), тоже без
изменений.
