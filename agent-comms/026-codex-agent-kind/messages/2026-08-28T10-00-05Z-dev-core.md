## 2. Твой пункт 2: чем теперь называется источник

`(default)` не различал «умолчание claude» и «умолчание кинда» — потому что это и был один общий default, и он назывался claude. Слоёв стало четыре, и последние два — разные факты, а не оттенки:

- `flag` — типнул человек;
- `machine` — путь назвал машинный конфиг (`agents.<kind>.exec`);
- `kind` — имя объявил кинд, который пакет реализует (`codex` → `codex`);
- `worker-id` — id воркера, взятый как имя: пакет такого кинда не знает, и это ДОГАДКА, сказанная вслух.

Ремонт (`agents['<worker>'].exec`) цитируется на обоих последних: тупик один и тот же, а знание пакета о кинде его не устраняет.

Порядок разрешения не тронут: флаг → машинный конфиг → имя кинда. Объявленный путь по-прежнему бьёт имя вендора — коробка, держащая codex там, куда `PATH` не достаёт, отвечает на вопрос, на который вендор ответить не может.
