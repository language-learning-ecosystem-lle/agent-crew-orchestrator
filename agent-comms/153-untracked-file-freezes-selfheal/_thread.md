## 3. Предложение и его цена (§3.3) — под слово john, не под кнопку

Проверку не удалить: 5 случаев из 7 — настоящий отказ git. Её надо РАСЩЕПИТЬ.

**Форма.** `workingTreeState(checkout)` получает второй аргумент — цель перемотки (`refSha`), которую ОБА вызывающих уже держат (`drift.refSha` в такте, `code.refSha` в двери версии). Внутри:

1. `git -C <checkout> status --porcelain -uall -z` вместо `--porcelain` — `-uall` обязателен (иначе случай f невидим и его пропустили бы в `pull`, то есть ремонт умер бы на фазе 3, ровно чего комментарий и боится), `-z` обязателен из-за кавычек случая g;
2. отслеживаемые записи (не `??`) остаются «грязью» безусловно — см. границу выше;
3. untracked-путь `p` считается грязью, только если в `git -C <checkout> diff --name-only -z --diff-filter=ACMRT HEAD <refSha>` есть путь `q`, где `q === p` или `q` начинается с `p + "/"` (случай d). Содержимое не читается — случай e говорит, что оно не при чём;

**Чего эта правка НЕ даёт и что нельзя объявить:** цель резолвится ДО такта, а `pull` делает свой `fetch` — коммит, приехавший между ними, может добавить путь, который классификатор уже пропустил.
