**Why:** поле `run-outcome` — единственный подъёмник парка `--parked-on run:N` (`park-seen.ts:108`, `thread.ts:777` читают ЗНАЧЕНИЕ, то есть номер PR, и больше ничего). За одно окно три штампа `run-outcome: 409`, и только ОДИН относился к текущей голове: класс воспроизводится сам собой всякий раз, когда голова двигается быстрее, чем идёт прогон.

**How to apply:** подняли письмом об исходе прогона — **сверь `PR_HEAD` письма с текущей головой PR прежде, чем искать работу**: строка «⚠️ Голова PR уже сдвинулась» в теле означает «этот такт поднят зря», и честный ход — сказать это и передать ход, а не выдумывать действие.
