Круг ревьюера кончается за ~35 секунд без `verdict.md` (шаг `claude-code-action` — 3 с, следом «Самопропуск действия»), и коммент в PR один и тот же в ДВУХ разных случаях:

1. **PR правит `claude-review.yml` сам** — версия ветки не совпадёт с дефолтной ДО merge, сколько кругов ни ставь; лечения нет по построению, ревью человеческое (см. [[guard3-field-class-dies-on-review-yml]]);
2. **ветка просто ОТСТАЛА** — воркфлоу уехал на `main`, дифф PR этих путей не трогает вовсе; лечение — перебазировка и метка заново.

`PROTOCOL.md` знает только случай 1, и его текст («подтянуть main неприменимо») в случае 2 читается ровно наоборот.

**Why:** случай 2 стоил целого круга ревью на #285 (тред 134, 2026-09-06): голова `3cebd9ba` отстала на три коммита, один из них — #278 по этому самому файлу.

**How to apply:** разводить одной командой — `git diff origin/main <голова> -- .github/workflows/`: пусто при своём диффе мимо этих путей = «просто отстал», перебазируй; не пусто = «правлю сам», ревью человеческое. И: **метка `review` переживает force-push** — перебазировал PR с меткой, снимай её тем же движением (круг не поднимется без события, а уведомитель молчит на PR с уже стоящей меткой — тихий замок).

**Из указателя (перенесено 2026-09-06, оглавление шло за потолок):** тот же коммент и та же зелёная джоба: «PR правит воркфлоу» (лечения нет) и «ветка отстала» (лечится перебазировкой); различает `git diff origin/main <голова> -- .github/workflows/`, а метка `review` переживает force-push
