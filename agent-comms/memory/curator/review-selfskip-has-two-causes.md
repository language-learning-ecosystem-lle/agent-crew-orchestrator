Круг ревьюера кончается за ~35 секунд без `verdict.md` (шаг `claude-code-action` — 3 с, следом «Самопропуск действия»), и коммент в PR один и тот же в ДВУХ разных случаях:

1. **PR правит `claude-review.yml` сам** — версия ветки не совпадёт с дефолтной ДО merge, сколько кругов ни ставь; лечения нет по построению, ревью человеческое (см. [[guard3-field-class-dies-on-review-yml]]);
2. **ветка просто ОТСТАЛА** — воркфлоу уехал на `main`, дифф PR этих путей не трогает вовсе; лечение — перебазировка и метка заново.

`PROTOCOL.md` знает только случай 1, и его текст («подтянуть main неприменимо») в случае 2 читается ровно наоборот.

**Why:** случай 2 стоил целого круга ревью на #285 (тред 134, 2026-09-06): голова `3cebd9ba` отстала на три коммита, один из них — #278 по этому самому файлу.

**How to apply:** разводить одной командой — `git diff origin/main <голова> -- .github/workflows/claude-review.yml`, и читать её ТАК:

- **пусто → самопропуска не будет, ребейз НЕ нужен.** Отставание ветки само по себе повода не даёт: действие самопропускается, пока файл ВЕТКИ не совпадает с дефолтным, а совпадение здесь бит в бит. Замерено 2026-09-07 на #326 (тред 155): голова `d7974a05` отставала на 3 коммита, дифф по этому файлу пуст — круг `34141499685` поднялся меткой и пошёл считать;
- **не пусто → два подслучая, и различает их СВОЙ дифф PR** (`gh pr view <n> --json files`): путь есть в файлах PR = «правлю сам» (лечения нет, ревью человеческое); пути в файлах PR нет = ветка отстала ОТ ПРАВКИ воркфлоу — вот здесь перебазировка и метка заново (случай #285).

**И вторая причина не ребейзить отставшую ветку — доставка вердикта версией НЕ красится.** Шаги доставки берут скрипт и исходники ВТОРЫМ чекаутом `ref: main` в `.code` (`claude-review.yml`), а `REVIEW_DELIVERY_CONFIG_REF` по умолчанию `origin/main` — исходники и конфиг всегда одна ревизия, поэтому бамп `protocolVersion` на `main` (26 против 25 у отставшей ветки) шаг доставки не роняет. Класс «PR, поднимающий версию схемы, красит доставку целиком» бьёт по `checks` НА САМОМ таком PR (замер #322), а не по кругу соседа.

И: **метка `review` переживает force-push** — перебазировал PR с меткой, снимай её тем же движением (круг не поднимется без события, а уведомитель молчит на PR с уже стоящей меткой — тихий замок).
