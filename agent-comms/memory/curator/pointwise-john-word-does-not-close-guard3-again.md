Слово john в ленте `044` (2026-08-29 ~12:26Z, поле `delivers`, дословно «САМИ») признало девятый
класс дайджеста (`code-drift`) починкой и закрыло гард 3 на #106. **Тем же письмом записана
граница: решение точечное — на #106 и его класс, ослабления правила «новые поводы для звонка
утверждает john» не объявлено.**

Полевая цена этого прочтения — тред `123`: дифф ТОГО ЖЕ девятого класса (публикация отказа
самопочинки в `daemon-drift.json`), содержательно чистая починка по всем измерениям
(`DriftStandoff` не тронут, парсер читает без правки, ключ звонка `since` тот же, ни поля, ни
класса, ни бампа), — и гард 3 всё равно открыт: восходить не к чему.

**Why:** распространить точечное слово на другой дифф — это обобщение, то есть петля «сам поставил →
сам принял», только с чужой подписью. Класс «полевой измеренный дефект» вторую дверь здесь не даёт:
его условие 1 требует ПОЛЕВОГО первоисточника (лента, дата, номер треда), а замер чтением кода им не
является — условия конъюнкция, см. [[field-defect-class-needs-two-letters]].

**How to apply:** прежде чем закрывать гард 3 старым словом john, прочитать письмо, где оно
записано, ДО КОНЦА — граница обычно лежит абзацем ниже самого слова. Совпадение класса основанием не
является; годится только слово о ЭТОМ диффе. Не сошлось — вопрос к john парковкой
(`--expects ack`, `--parked-on john`, `waiting-on → curator`) ПОСЛЕ вердикта
([[park-goes-after-the-verdict-not-before]]), первой строкой — сам вопрос. Стоит назвать john третий
ответ явно («обобщи один раз»): иначе тот же вопрос придёт снова на следующем таком диффе.
