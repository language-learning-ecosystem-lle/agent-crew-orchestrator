Потолок 24 576 б (`memoryIndexAlarmFor`, `memory.ts`) мерит **`MEMORY.md`, а не каталог**. Замер своей рукой 2026-09-03 на куче `curator` (31 308 б = 127,4 %): 19 784 символа, из них **указатели (заголовок + ссылка) — 3 535 (17,9 %), проза крючков — 16 249 (82,1 %)**. Кириллица — два байта на символ, поэтому `stat -c%s` и `awk length` расходятся законно в 1,58 раза; называть, каким из двух мерил.

**Следствие 1 — чем это гасится.** 53 указателя сами по себе стоят ≈5 600 б (23 % потолка), значит переполнение — это ДЛИНА крючка. Дешёвая и безвредная операция: старый крючок переносится ДОСЛОВНО в тело своей заметки строкой-пометкой, в оглавлении остаётся короткий. Так 31 заметка дала 31 308 → 17 488 б (127,4 % → 71,2 %) за один такт, без удаления ни одной заметки (53 было, 53 осталось, осиротевших указателей 0 — проверять перечислением имён файлов в `MEMORY.md`). Платится точность отзыва: короткий крючок хуже наводит, заметку приходится открывать чаще.

**Следствие 2 — механизм #239 сюда не достаёт.** `planExtinction` (`memory-cause.ts`, влит `d5dc4e7d` 2026-09-03) гасит заметку по **поводу** — полю `thread:` во фронтматтере — при закрытии этого треда; заметка без повода не гаснет НИКОГДА (слово john, тред `090`). На куче `curator` поводов ноль и по существу быть не может: все 53 — про устройство мира, то есть ровно тот бессмертный сорт. Гасить нечего, а оглавление платится каждый такт — поэтому вопрос про механизм на длину строки ушёл к john (`090`, парковка 2026-09-03T14:54Z).

**Следствие 3 — «7 заметок со словами самоотмены» класса не образуют.** Грепом по прозе («больше не», «устарел», «неверно») ловятся ФАКТЫ, а не объявления смерти: «рукой зелёный больше не снимают», «время оценивается в разы неверно». Перечислено поимённо с чтением контекста — самоотменяющихся ноль. Тот же капкан, что в [[verify-the-grep-pattern-not-its-result]], и закрывается он перечислением — [[field-sample-criterion-yields-to-enumeration]].

**How to apply:** звонок тревоги («memory: the index of …») читать как «крючки разрослись», а не «заметок много»: мерить оба слагаемых (`awk -F' — '` по указателю и по хвосту), сокращать крючки с переносом текста в тело, и не ждать, что смерть по поводу это подвинет. Влитое ≠ работающее — гашение живёт только когда демон перезапущен на sha с мержем ([[merged-code-is-not-running-code]]).
