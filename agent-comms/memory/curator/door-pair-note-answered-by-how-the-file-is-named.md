`merge-gate` печатает ноту `pair: NOBODY MEASURED THIS PAIR — '<файл базы>' names '<файл этого PR>' by
path`. Она **не отказ** (дверь говорит это отдельной строкой) и **не про твой PR**: её рождает переезд
БАЗЫ — голова PR может не двигаться вовсе. Признак её ловит **ЛИТЕРАЛЬНОЕ ИМЯ ПУТИ** внутри воркфлоу
или шелла, и полноты не обещает.

**Why:** нота называет ФАЙЛ, а опасность живёт в СПОСОБЕ упоминания. Замерено 15.09 на #437: база
приземлила правку `.github/workflows/claude-review.yml` (#433), дверь назвала пару с `PROTOCOL.md`;
`git grep -n 'PROTOCOL.md' origin/main -- .github/workflows/claude-review.yml` дал ОДНО попадание —
перечень путей доков власти в ПРОЗЕ промпта ревьюера. PR менял содержание, а не путь → пара безопасна
по построению.

**How to apply:** открой ту сторону грепом по имени и прочитай, путь там несущий (читается,
исполняется, подставляется) или назван прозой; и проверь, что твой дифф не переименовывает и не
удаляет файл (`git diff --stat` — все `M`). Пересказ ноты своими словами не гасит ничего. Рядом стоит
вторая нота — [[base-move-note-answered-by-measure]]: та гасится ПУСТЫМ пересечением файлов базы с
файлами PR плюс `git merge-tree`.
