Круг ревью, умерший ДО суждения, оставляет на голове красный чек с именем `review`, и
`merge-gate` печатает `STOP guard 2 · not green: review=FAILURE` — хотя до метки гард 2 на той
же голове был зелёным. Замерено 2026-09-13 на PR #378 (голова `d59790b50`): прогон `34749640516`
упал на `App token exchange failed: 503` внутри объявленной аварии GitHub (инцидент 09:16Z,
`Pull Requests — major_outage`), `verdict.md` не создан, ни одна из трёх доставок не сработала.

**Why:** «нет вердикта» читается как проблема только гарда 1, и кажется, что кнопка ждёт ревью.
На деле кнопка невозможна и по гарду 2, то есть НИКАКАЯ рука (включая john) PR не смёржит, пока
чек красный.

**How to apply:** ОДИН успешный круг на той же голове закрывает оба гарда разом — новый чек
`review` перекрывает красный. Отдельного действия под гард 2 не изобретать и голову не двигать.
Повторный подъём круга — только перевешивание метки ([[merge-with-match-head-commit]] про кнопку,
[[review-circles-are-countable]] про счёт кругов); внутрь живой аварии платформы вторая попытка
покупает второй красный чек, а не вердикт.
