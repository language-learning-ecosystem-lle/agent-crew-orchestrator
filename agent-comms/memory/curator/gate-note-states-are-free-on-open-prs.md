Живая приёмка печатной ноты двери `merge-gate` не требует ни подделок, ни своего PR: список
`gh pr list --state open` уже содержит головы в РАЗНЫХ состояниях, и один прогон двери по каждой
снимает по состоянию. Замерено 2026-09-06 на ноте `note · pair` (тред 136, PR #316): PR без
зелёного чека дал «незамер сказан одной строкой», а PR с ЖИВЫМ дрейфом базы и без узкого признака —
контрольный ноль (ни строки), причём дрейф ему устроил мой же сквош минутой раньше.

**Why:** приёмка «нота молчит, когда должна» иначе выглядит недоказуемой (молчание неотличимо от
«дверь не смотрела»), и роль тянется либо к фикстуре, либо к своему PR — то есть к собственной руке
в замере.

**How to apply:** прогнать смёрженную дверь по каждому открытому PR и назвать в следе, какое
состояние каким PR закрыто; состояние, которого в поле нет, объявить непокрытым, а не подделывать.
Сверять и код выхода: он обязан приходить от гардов, а не от ноты. Дерево при этом — чекаут сквоша,
см. [[acceptance-on-the-merged-tree-is-cheap]] и [[base-move-note-answered-by-measure]].
