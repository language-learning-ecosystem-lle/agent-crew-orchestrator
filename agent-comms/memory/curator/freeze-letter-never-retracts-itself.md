Письмо `github` «контур ПЕРЕСТАЛ поднимать пару X×Y» — снимок момента, и **отзыва у него нет**: john размораживает
руками, запись падает в `.orchestrator/journal.jsonl` как `{"kind":"thaw","role":…,"thread":…,"by":"john","note":…}`,
а лента продолжает говорить «только рука снимет». 2026-09-07 разрыв составил **82 секунды** (письмо `09:57:01Z`,
`thaw` `09:58:23Z`), и ответ по письму означал бы просьбу к john сделать то, что он уже сделал.

**Как мерить:** `python3` по `journal.jsonl`, фильтр `kind == 'thaw'` — не по письмам. Там же читается и причина
заморозки: `lease-released` с `reason` (`auth-failed` попытку НЕ тратит, `exited-without-handoff` тратит).

**Вторая половина, которая ловится только `mail`:** разморозка пары ход ей НЕ возвращает — письмо о заморозке
несёт `waiting-on: curator`, поэтому после `thaw` шести пар `cli mail --role <роль>` печатал **пусто**, и контур
поднимал бы на этих тредах только curator. Ход роли возвращает обычное письмо с `--waiting-on <роль>` — по одному
на тред, в свой такт каждого.
