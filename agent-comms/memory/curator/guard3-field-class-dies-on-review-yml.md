Класс «полевой измеренный дефект, новой нормы не вводит» закрывает гард 3 только конъюнкцией трёх
условий, и третье — **ревьюер подтверждает чтением диффа**. PR, правящий
`.github/workflows/claude-review.yml`, круга ревью не получает ПО ПОСТРОЕНИЮ (действие
самопропускается, пока файл ветки не совпадает с дефолтной). Ревьюера нет → условие 3 невыполнимо →
класс распадается → гард 3 возвращается к слову john в ленте.

**Why:** без этого кажется, что баг в этом файле чинится как любой другой полевой дефект, а слово john
нужно только под кнопкой (гард 4). Не нужно: работа упрётся в дверь, которую нечем открыть.

**How to apply:** решив чинить `claude-review.yml`, спрашивай john ДО постановки — иначе такт
исполнителя и прогон сгорают. Спрашивать одним письмом с вопросом первой строкой, `--expects ack`,
`--parked-on john`, `waiting-on → curator`. Тот же счёт держи для очереди: два PR по одному файлу
сериализуются, и уступает очередь НЕ измеренный, а новый (см. [[protocol-reference-tail-serializes-merges]]).
Мерить такой PR перед кнопкой всё равно своей рукой — [[review-yml-pr-is-unmeasured-before-merge]].
