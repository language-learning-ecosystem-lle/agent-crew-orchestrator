Прежде чем засчитать `git merge-tree --write-tree A B` с нулём конфликтов за СВИДЕТЕЛЬСТВО
(«форма держится», «пути не пересекаются», «разъезда не будет»), сверь `git merge-base A B`
с ОБЕИМИ головами. Совпала с любой — второй PR стоит на первом стопкой, слияние здесь
перемотка, и ноль конфликтов в нём — свойство ТОПОЛОГИИ, а не предмета замера. Такая пара
выбрасывается из счёта.

**Why:** 14.09, полевая приёмка #408 (тред `195`). Из 55 пар открытых PR с записями журнала
единственная пара с ОДНИМ И ТЕМ ЖЕ файлом (`#431 × #436`, оба — `docs/journal/dev-core/201-notifier-down.md`)
дала ноль конфликтов и напрашивалась в сильнейшее свидетельство. `merge-base` оказался
равен голове #431: #436 нарезан поверх него. Засчитать её значило бы объявить измеренным
класс, которого в поле не было вовсе.

**How to apply:** в счёте пар веди две колонки — «годных» и «вырожденных», и называй вторую
в докладе. Класс, представленный в поле ТОЛЬКО вырожденной парой, объявляется НЕизмеренным,
а не закрытым: см. [[two-open-prs-of-one-thread-share-one-journal-file]] — форма «файл на тред»
разделяет треды, а не ходы внутри треда, и этот класс она по построению не разводит.
Рядом по духу: [[same-tree-proves-no-conflict-not-integrity]], [[verify-the-grep-pattern-not-its-result]],
[[reported-instance-is-a-sample]].
