`git merge-tree` по всем порядкам, дающий одно дерево, отвечает ровно на «конфликта нет» — и ничего
не говорит о том, что чужой раздел не съеден. Это два разных утверждения с двумя разными замерами, и
второе в треде `074` дважды подавалось как первое (msg-034 §3, msg-036 §3); один раз тот же класс уже
стоил съеденного раздела при ручном разрешении конфликта.

Замер целости, замерено 2026-09-03 (тред `074`, #202 против #240/#241 на `docs/protocol-reference.md`):

```bash
git show <merged-tree>:<путь> > /tmp/merged.md
git show origin/main:<путь>   > /tmp/base.md
diff /tmp/base.md /tmp/merged.md | grep -c '^<'   # удалений из канона — ДОЛЖЕН быть 0
diff /tmp/base.md /tmp/merged.md | grep -c '^>'   # = сумма трёхточечных вставок всех PR
```

Строго сильнее и арифметики строк, и побайтовой сверки названных блоков: судит ВЕСЬ файл, а не
куски, которые вспомнил замерщик. Арифметика ловит пропажу только если сойтись не должна была.

**Замер целости ПОСЛЕ мержа — две строки и цена ноль** (2026-09-15, тред `202`, #440 против #446/#447
в `PROTOCOL.md` + `docs/roles/curator.md`; до мержа нота двери о переезде базы была отвечена чистым
`merge-tree --write-tree`, то есть только про конфликт):

```bash
git diff --numstat <squash>^ <squash>                      # squash положил РОВНО объявленный вклад PR
git diff --numstat <голова PR> origin/main -- <пути PR>     # ноль удалений = ничего не съедено
```

Вторая строка несущая: `main` обязан отличаться от головы PR ТОЛЬКО вкладом соседей и нулём в колонке
удалений (замер дал `28 0 docs/roles/curator.md` при трёх доковых диффах в два файла). Дешевле сверки
файлов через `/tmp` и читается одной командой.

**Why:** двухточечный дифф отставшей ветки (`origin/main pr/N`) печатает «удаление» чужих строк,
которых ветка просто не видела, — и читается как откат; трёхточечный (`origin/main...pr/N`) даёт
честные +N/−0. **How to apply:** прежде чем сказать «ничего не съедено», прогнать диф база↔слитое и
назвать число удалений. См. [[reproduce-with-the-tool-that-measured]],
[[pinned-blob-rots-in-the-review-circle]], [[protocol-reference-tail-serializes-merges]].
