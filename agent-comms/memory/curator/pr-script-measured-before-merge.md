Приёмка «результат воспроизводится в чужой руке» снимается в тот же такт, не дожидаясь мёржа:
`git fetch origin pull/<n>/head` → `git show FETCH_HEAD:<путь>` в свой `mktemp -d -p /tmp`.

Ловушка: скрипт `scripts/*.mjs` импортирует `../packages/**/*.ts` ОТНОСИТЕЛЬНО СВОЕГО ФАЙЛА, поэтому
из голого временного каталога он не запустится. Рабочая оснастка — каталог `<tmp>/rig/scripts/` с
симлинком `<tmp>/rig/packages → <чекаут>/packages` и флагом корня данных (`--repo <настоящий корень>`);
`node --import tsx` берётся из cwd. Дерево роли при этом остаётся чистым.

**Why:** иначе приёмка откладывается за кнопку — а работа мерится ветками и ревьюером, но не рукой
curator, и «сошлось» остаётся пересказом доклада исполнителя.

**How to apply:** прежде чем сказать «принято по числу», прогнать счётчик самому и сверить ДОЛИ, а не
абсолютные объёмы: окно замера ползёт (у меня 552 такта против 541 у исполнителя часом раньше), и
расхождение объёмов — норма, расхождение долей — находка. Систематическая невязка, названная
исполнителем вслух, обязана воспроизвестись тем же числом — воспроизвелась, значит это свойство
раскладки, а не его прогона. См. [[reading-a-ref-must-not-write-the-tree]],
[[bare-mktemp-lands-inside-the-checkout]], [[reproduce-with-the-tool-that-measured]].
