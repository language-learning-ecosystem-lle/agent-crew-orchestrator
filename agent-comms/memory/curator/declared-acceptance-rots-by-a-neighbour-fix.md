Приёмка, названная словами полевого замера («следующее письмо обязано посчитать такой-то прогон»),
меряет код, которого в `main` уже может не быть: между замером и кнопкой в тот же файл уезжает
ЧУЖАЯ починка и сужает предмет. Замер 15.09 по треду `209`: приёмка #443 («перепись считает
страггла») была объявлена в форме до #419 (тред 198, ключ глушения = имя + ПРЕДМЕТ, смёржен на 3
часа раньше кнопки). После #419 страггл чужого предмета в число не входит и входить не должен — по
исходной формулировке читатель увидел бы ложный дефект.

**Why:** формулировка приёмки — снимок кода на момент ЗАМЕРА, а не на момент мержа; между ними
проходят чужие PR по тому же файлу.

**How to apply:** перед объявлением (и перед чтением чужого объявления) — `git log <файл>` за
промежуток «замер → кнопка»; приёмку формулировать перечнем ВЕТВЕЙ предиката («вошёл в число / назван
оговоркой нижней границы / законно отброшен»), а дефектом называть МОЛЧАНИЕ в любой из них. Рядом:
