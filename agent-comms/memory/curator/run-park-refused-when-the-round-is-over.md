Дверь `new-message` сверяет источник только у парка `run:N`, и отказов у неё ДВА: «на голове нет
ни одного прогона» и отдельно «круг уже кончился» — если ни один прогон на голове не `queued` и не
`in_progress` (README пакета, раздел Commands, тред 032). Проверяется одной командой перед письмом:
`gh api 'repos/<owner>/<repo>/actions/runs?head_sha=<sha>' --jq '.workflow_runs[] | .status'`.

**Why:** после УПАВШЕГО круга инстинкт — «запаркуюсь на run:N и пусть разбудит следующий прогон».
Ждать нечего: лифт парка смотрит только вперёд, а исход уже лежит в ленте ПОЗАДИ парка.

**How to apply:** нечего ждать прогоном и следующее действие механическое и своё — ход передаётся
на себя БЕЗ парка (`--waiting-on curator`, и тогда `--expects none`: дверь отказывает связке
`--expects ack` + `waiting-on curator` + без парка как состоянию без законного исхода). Парк на
человеке тут тоже неверен — он заморозит тред за чужим словом, которого работа не ждёт.
Замер 2026-09-13 09:57Z (тред `187`, PR #381): отказ СЧИТАЕТ прогоны вслух — «every run on head
`08c6db955` has ALREADY FINISHED (2 runs, none queued or in progress)», а принятый парк печатает
«waits for a run that is still running (1 of 3 on head …)». Отсюда форма, когда ждать ЕСТЬ чего:
парк ставится ПОСЛЕ действия, поднимающего прогон (push, перевешивание метки), и прогон перемеряется
между действием и письмом — он появляется за ~1–40 с.

**Оговорка, замеренная 2026-09-13 (тред `182`, PR #378): «на себя БЕЗ парка» стоит ПОДЪЁМ, и
внешняя помеха его съедает.** Ход передан на себя без парка в 09:49Z — контур поднял пару в
**09:51Z, через две минуты**, и весь такт ушёл на подтверждение, что авария GitHub (`Pull Requests`
= `major_outage`, инцидент от 09:16Z) не снята. Механическое действие своей рукой (перевесить метку)
было заблокировано НЕ прогоном и НЕ чужим словом, а платформой, — а формы парка на внешнюю помеху не
существует: `parkedOnFrom` знает только человека, `pr:N` и `run:N`. Отсюда развилка: следующее
действие своё и ВЫПОЛНИМО — на себя без парка; своё, но заперто снаружи — парк на ЧЕЛОВЕКЕ
(`--expects ack`, звонит сразу первой строкой), и вопрос ему ставится настоящий, а не предлог:
«платить ли за вторую попытку в аварию» — это расход, то есть его граница. Иначе третий подъём
подряд принесёт те же строки статус-страницы.
