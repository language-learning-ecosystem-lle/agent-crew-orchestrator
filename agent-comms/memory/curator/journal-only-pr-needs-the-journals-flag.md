Дверь снимает гард 1 с диффа, ВСЕ пути которого лежат в журналах ролей (решение john 2026-09-11,
тред 187), и печатает его как `ok · not asked`. Но исключение включает ФЛАГ: без
`--journals docs/journal` гард 1 спрашивает `approve`, которого на таком PR не будет НИКОГДА —
метка `review` на журнальный дифф не вешается, — и PR становится неотказуемым.

Полная строка: `pnpm protocol merge-gate --ref origin/main --pr <n> --review-workflow 'Claude PR Review' --journals docs/journal`.

**Why:** замерено на #403 (13.09): та же голова без флага и с флагом даёт разные вердикты гарда 1,
а курьер в это же время зовёт автора на метку ШАБЛОНОМ, не глядя на содержимое диффа
([[courier-calls-for-a-label-on-a-journal-only-pr]]) — то есть и зов, и дверь без флага толкают к
оплаченному кругу, против которого решение 187 и вводилось.

**How to apply:** на журнальном PR флаг ставится сразу; зов курьера на метку не исполняется;
восхождение — стоячие нормы, и пять признаков нормы всё равно читаются построчно
([[journal-pr-guard3-rests-on-standing-norms]]). Гарды 2–5 флаг не трогает: один путь вне журналов —
и исключения нет.
