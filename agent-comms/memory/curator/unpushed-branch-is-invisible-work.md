Сессия, свёрнутая по сроку, коммитит «как есть» — но **коммит без push для контура не существует**:
ни почта, ни `gh`, ни следующая сессия его не видят. 2026-09-03 предыдущая сессия curator написала
всю правку треда 052 и умерла за минуту до старта следующей, не запушив ветку и не написав в тред
ни строки; нашлась она случайно — отказом `git checkout -b` на занятом имени. Имя ветки другое —
контур заплатил бы за одну и ту же работу дважды.

**Why:** роли делят один склад refs ([[role-worktrees-share-one-ref-store]]), поэтому чужая и своя
прошлая работа ЛЕЖИТ рядом и читается бесплатно — но только если её спросить.

**How to apply:** перед тем как писать дифф по постановке, спросить склад:
`git branch -a --list '*<номер треда>*'` и `git log --oneline origin/main..<ветка>`. Нашлась —
прочитать дифф целиком и брать её работу, а свою выбрасывать (её дифф обычно шире: прошлая сессия
успела больше, чем видно по треду). Своё сворачивание кончается **push'ем ветки**, а не коммитом;
без него доклад «закоммичено» неправда по существу. Смежное:
[[statement-of-work-ends-at-the-tag]], [[merged-code-is-not-running-code]].
