Круг ревьюера, сгоревший на ЛИМИТЕ АККАУНТА, мерится из публичного лога прогона записью `result`:
`is_error: true` при `subtype: "success"`, **`num_turns: 1`, `total_cost_usd: 0`, `modelUsage: {}`**,
`duration_ms` ~400. Эта форма доказывает, что диффа сессия не читала ВООБЩЕ — суждения нет, есть
стена.

**Машинных полей `api_error_status: 429` / `terminal_reason: api_error` в логе НЕТ** — они лежат в
`execution_file`, который читает только шаг доставки, и приезжают письмом `reviewer-pr`. Грепать лог
по `429`/`api_error_status` бесполезно: попадаются лишь эхо-строки самого yaml-шага (фильтровать
`grep -v '36;1m'`).

**Оракул ДЕШЕВЛЕ лога — ДЛИТЕЛЬНОСТЬ круга**, и поле разделяется без пересечений (перечислено
2026-09-13, 12 кругов за сутки: 5 `failure` — **45…56 с**, 7 `success` — **299…572 с**):
`gh run list --workflow claude-review.yml --limit 12 --json databaseId,createdAt,updatedAt,conclusion,headSha`.
Меньше минуты = до модели не дошёл; дольше ~2 минут = стену прошёл и дифф читает. **Стена бывает
ОКНОМ, а не свойством диффа:** те же головы `dee8521e`/`52742cd5`, умершие в 13:14/13:19Z, прошли
успешно в 13:41/13:42Z — лечит ПОВТОР метки, а не правка.

**Why:** письмо ревьюера — заявление, а «работа не принимается по косвенному признаку». Запись
`result` даёт независимое подтверждение той же руки и стоит одну команду.

**How to apply:** `gh run view <id> --log | grep -n -B12 '"is_error": true'`, затем прочитать 6 строк
записи. Ноль стоимости + один ход = дифф не судился, значит гард 1 `STOP` и третье условие полевого
класса гарда 3 (чтение диффа ревьюером) ОТКРЫТО — человеческое чтение curator их не закрывает
(исключение гарда 1 только для PR по `claude-review.yml`). Время ресета берётся ЦИТАТОЙ строки
`result` из письма и в дату не разбирается — формат её никто не обещал. До ресета перезапуск
запрещён; парка под это нет ни одного ([[run-park-refused-when-the-round-is-over]]), поэтому
концовка — парк на ЧЕЛОВЕКЕ. Связано: [[failed-review-run-reddens-guard2]],
[[review-circle-verdict-lands-in-minutes]].
