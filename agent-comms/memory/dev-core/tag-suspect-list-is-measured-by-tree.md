`scripts/split-package.sh` печатает предупреждение «теги пакета, чьё дерево в линии НЕ
встречается (срезаны с невлитого)». Мера — **дерево**: тег пригоден, если его `^{tree}` равен
`<prefix>` на КАКОМ-ТО коммите линии.

**Отсюда несимметрия, на которой легко ошибиться:** попадание в перечень — сильный сигнал, а
ОТСУТСТВИЕ в нём не доказывает ничего о том, как тег резали. Тег, срезанный с невлитой головы,
покидает перечень сам собой, как только та голова вливается штатно.

Замерено 2026-09-07 при резе `agent-protocol-v0.2.11`: `agent-protocol-v0.2.8` — канонический
случай треда `095` (срезан за 45 секунд ДО открытия PR #155) — в перечне **не назван**, потому
что его дерево в линии теперь встречается. Назвал перечень только `v0.2.0` и `v0.2.5`.

**Как применять:** «тега нет в предупреждении» ≠ «тег прошёл merge-гарды». Хочешь знать, как
резали конкретный тег, — мерь `git log`/дату тега против `mergedAt` его PR, а не вывод скрипта.
