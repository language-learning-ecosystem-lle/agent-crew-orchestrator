`threadNumberTaker` (`packages/agent-protocol/src/thread/write.ts`) ищет чужой тред с ТЕМ ЖЕ
номером; полный id проверяется только существованием каталога. Значит `076-main-red-alarm` и
`112-main-red-alarm` живут рядом законно.

**И отсюда инверсия риска, замеренная 2026-09-06 (тред `147`):** сопоставление треда ВЕЗДЕ идёт по
ПОЛНОМУ имени — грепы доставки берут `NNN-slug` целиком и спрашивают каталог точным путём, дверь
почты делает `join(root, id)`, ключи `notify.state` — `role\tthread`. Сравнения по префиксу нет
нигде, поэтому **коллизия НОМЕРА безвредна** (два каталога — два разных адреса), а опасна
**коллизия СЛАГА**: единственная дверь не по полному имени — `--ensure-thread <slug>`
(`chooseReceiver`, стоячие адреса), она берёт открытый непаркованный тред этого слага, при
нескольких — с бо́льшим номером.

**How to apply:** шаблон имени для серии однотипных тредов (сменяющие друг друга приёмники
уведомителя) не требует ни даты в слаге, ни правки двери — тот же слаг плюс следующий свободный
номер. Но слаг, который является СТОЯЧИМ АДРЕСОМ, повторять вне этой серии нельзя: событие уедет
в новейший открытый тред слага. Связано: [[silent-loss-is-the-unraised-turn]],
[[do-not-park-a-standing-address]].
