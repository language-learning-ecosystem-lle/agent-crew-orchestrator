Пачка звонков смотрителя в `077-notifier-down` разбирается не письмо за письмом, а одним
`gh run view <id> --log-failed | grep 'could not be read'`: девять отказов `Comms Derived`
2026-09-02 16:40–16:52 дали одну строку — тред `116-role-memory-cost` открыт без `_meta.md`,
`derive` пишет производные БЕЗ него и выходит кодом 2 намеренно (механизм треда 060).

**Почему:** письмо приходит на КАЖДЫЙ красный прогон, а прогон поднимает КАЖДЫЙ push в `comms`.
Пока голова треда не починена, число писем = число записей почты в окно, и к числу причин
отношения не имеет. Проверять «а не сам ли смотритель себя кормит» стоит (его письмо тоже
пушится в `comms`), но 2026-09-02 гипотеза не подтвердилась: головы всех девяти прогонов —
обычные записи почты.

**How to apply:** взять последний отказ, вынуть причину, найти коммит починки
(`git log origin/comms -- <тред>/_meta.md`) и проверить конclusion ближайшего прогона ПОСЛЕ него —
класс закрывается на этом, остальные письма разбора не требуют. Починка головы — `thread status
--repair`, право `thread-status` у dev-core нет, чинит curator. Связано с
[[red-main-checks-may-be-comms-sync]].
