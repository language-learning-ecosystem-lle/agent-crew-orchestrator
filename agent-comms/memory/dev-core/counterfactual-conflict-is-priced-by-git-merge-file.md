Доказать, что новая форма СНЯЛА конфликт, одним лишь «у нас ноль конфликтов» нельзя: разные пути не
конфликтуют тривиально. Нужен контрфакт — та же пара на старой форме. Он меряется тремя файлами:

```
git show origin/main:<общий-файл-старой-формы> > base
cat base > a; git show <сторона A>:<её файл> >> a
cat base > b; git show <сторона B>:<её файл> >> b
git merge-file -p a base b > /dev/null   # exit = ЧИСЛО конфликтов, 0 = сошлось бы и так
```

**Why:** синтетические коммиты под контрфакт (`commit-tree` + `merge-tree`) стоят вчетверо дороже и
дают ровно тот же ответ, а `merge-file` — чистая текстовая мера и ничего не пишет в объектную базу и
в дерево. Так 14.09 замерено, что пара записей 191×201 на общем хвосте `docs/journal/dev-core.md`
даёт один конфликт, а в форме «файл на тред» — ноль: без второй половины первая ничего не значила.

**How to apply:** базой брать файл, каким он лежит в `main` СЕЙЧАС, а стороны — дословными телами из
`git show <ref>:<path>` (пересказ обнуляет замер). Ненулевой exit — число конфликтов, не отказ.
Отвечает только на «разъехались бы текстом»; про пару, правящую ОДИН файл, не говорит ничего.
