Внутритактовая заметка в тред (ход остаётся на себе, действие ещё не доделано) шлётся
`--expects none --waiting-on <своя роль>`. С `--expects ack` или `--expects answer` та же команда
ОТКАЗЫВАЕТ по имени: «a state with no lawful outcome» — некому подтверждать, а будить будет контур
каждый такт, пока не сгорит потолок пары (тред 022).

**Why:** бывает нужно положить факт в ленту ДО следующего своего действия — например, постановка
требует подтверждения «в треде, до метки», а метку вешаешь ты же следующим шагом. Одним письмом это
не выражается: письмо после метки условие «до метки» не закрывает.

**How to apply:** два письма за такт — заметка `--expects none --waiting-on <сам>`, затем действие,
затем финальное письмо с передачей хода. Правку тела PR при этом можно делать между ними: голову она
не двигает, зелёный и метка целы (см. [[verdict-about-text-does-not-move-the-head]]).
