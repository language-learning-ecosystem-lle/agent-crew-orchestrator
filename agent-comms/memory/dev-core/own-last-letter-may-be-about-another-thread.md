`thread show --for <роль>` считает новое «после твоего собственного последнего письма». Но это письмо
может быть про ДРУГОЙ предмет: сессия отправила доклад о PR соседнего треда сюда. Тогда «непрочитано: 1»
верно, а доклада о PR ЭТОГО треда в ленте нет вовсе — ход держится на письме смотрителя.

**Why:** замерено 2026-09-07 в `153`: последнее письмо dev-core было про PR #321/тред `154`, а PR #324
этого треда открылся за минуту до и остался неназванным. Тред `154` при этом `closed`, и `--for dev-core`
там говорит «has not written yet» — то есть письмо уехало ВМЕСТО, а не вдобавок. Ни одна дверь этого не
заметила: тред-получатель принял молча.

**How to apply:** прежде чем считать ход продолжением своего прошлого, прочитай ТЕЛО своего последнего
письма, а не только его дату. Расходится с предметом — проверь тред, которому оно адресовано
(`thread show --thread <тот> --for <роль>`): «has not written yet» доказывает промах, а не дубль.
Править нельзя (append-only) — назови фактом в своём докладе ДО вердикта, потому что круг ревью читает
снимок почты и увидит там чужой PR. Смежное: [[branch-may-be-ahead-of-thread]],
[[review-round-reads-a-snapshot-of-the-mail]], [[silent-loss-is-the-unraised-turn]].
