Перед меткой `review` смотреть на **ноту гарда 2 о базе** в `merge-gate`, а не на `mergeable`/`mergeStateStatus`: PR бывает `MERGEABLE`/`CLEAN` и при этом несёт `the base moved AFTER the credited checks started`. **Но нота — это ВОПРОС, а не отказ.** Отвечать на него замером, а не перебазировкой рефлексом:

```
OLD=$(git merge-tree --write-tree <зачтённая-база> <ветка>)
NEW=$(git merge-tree --write-tree origin/main <ветка>)
git diff --stat $OLD $NEW
```

Разошлись только на файлы, которых нет в диффе PR (и `git grep` по ветке их не поминает) — **сдвиг инертен, метку вешать можно**. Разошлись внутри путей PR — перебазировка нужна.

**Непересечения путей НЕ ХВАТАЕТ, когда дифф PR — процессный (или интеграционный) тест, а сдвиг задел модуль, который этот тест гоняет.** Ожидание такого теста есть функция от того, что печатает модуль: пути не пересеклись, поведения — могли. Тогда мерить само склеенное дерево, а не таблицу файлов:

```
NEW=$(git merge-tree --write-tree origin/main <ветка>)
git checkout --detach $(git commit-tree $NEW -p origin/main -m probe)   # node_modules переживает
<прогон поверхности, где половины могли встретиться>
git checkout --detach <база>                                            # ветка не тронута
```

Полевой случай 2026-08-31, #177: дифф — один `notify.process.test.ts`, сдвиг базы принёс #178 с +202 строками в `notify.ts`. Пересечение путей пустое, но модуль под тестом — один и тот же; замер склеенного дерева (156/156, включая прогон внутри красного часа) сдвиг закрыл, перебазировка не понадобилась. Границу замера называть в треде: поверхность прогнана, полный `pnpm test` на склейке не мерил никто.

**Why:** дверь сама печатает `Conservative: a base move that cannot change the merge is named too` — она знает, что называет лишнее, но отличить не умеет. Условие «нота пуста» на живом контуре НЕДОСТИЖИМО, а не строго: цикл CI ~35 мин, база уезжает чаще (8 перебазировок за 15 тактов на #160, дважды за один такт). Правило, которое нельзя выполнить, ветку не защищает — оно её топит. И нота — суждение о кнопке merge (гард 2 = дверь мержа), а не о праве отдать голову на ревью: ревьюер читает дерево головы, а кнопку с этой же нотой держит curator.

**How to apply:** такт начинать с `pnpm protocol merge-gate --ref origin/main --pr <N> --review-workflow 'Claude PR Review'`, читать ноту гарда 2 → мерить `merge-tree` → инертен, значит метка на зелёную голову, и отступление назвать в треде числами (какие деревья, чем разошлись, ноль перекрёстных ссылок). Честно оговаривать границу: объединение половин не мерил ни один прогон — это вывод из непересечения, не факт. Парковка — [[parked-on-run-takes-pr-number]], выбор формы — [[park-pr-vs-run-choice]].
