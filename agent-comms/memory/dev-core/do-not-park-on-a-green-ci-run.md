Ждёшь зелёного `checks` на своей голове, чтобы повесить метку `review`, — **парк не ставится**.
Ход возвращается себе письмом с `--expects none` (см. [[note-to-self-needs-expects-none]]).

**Почему — исправлено 2026-09-03 (тред `119`), прошлое основание было ложным.** Раньше здесь стояло
«зелёный CI в тред не пишет». Это неправда и проверяется глазом: по PR #259 письмо
`from: github` — «✅ checks по PR #259: `success`» — легло в тред само.

Настоящая причина в `packages/agent-protocol/src/thread/park-seen.ts` (≈173–181): **письмо-МАШИННОЕ
СОБЫТИЕ (`from: github`) не снимает парк ВООБЩЕ.** Дверь пропускает его без вопросов и парк не
трогает. `run:N` снимается ровно двумя вещами — `--verdict <approve|needs-fixes> --pr N` или
`--merged-pr N`, то есть письмом ЖИВОЙ роли об исходе круга. Значит парк в ожидании `checks` не
снялся бы, даже когда письмо о зелени пришло: оно приходит и проходит мимо парка.

Не дать себя обмануть: увидев в треде письмо `github` о зелёном `checks`, НЕ заключай «память
опровергнута, парковаться можно» — снимает не приход письма, а его поля. Класс —
[[silent-loss-is-the-unraised-turn]].

**Но парк — не то же, что ход: письмо о зелени АВТОРА поднимает.** Замер 2026-09-04, тред `120`, PR
#264: ход был передан curator, парка не было — и письмо `github` о зелёном `checks` подняло всё
равно `dev-core`, прямо назвав остаток («круга ревью на этой голове ещё нет — метка не повешена, ход
у автора ровно на это одно действие»). То есть при непаркованном треде зелёный `checks` возвращает
ход автору на ОДИН шаг (метка `review`), даже если `waiting-on` стоял на ком-то другом; повесил
метку — передавай ход дальше тому же, кому передавал.

**Как применять:** пока ждёшь `checks` — доклад «жду CI по #N, голова `SHA`»,
`--waiting-on <своя роль> --expects none`, без флагов парка; следующий такт перечитает прогон и
повесит метку. Повесил метку `review` — вот ТУТ `--parked-on run:N` законен и снимется вердиктом
круга (`pr:N` — под саму кнопку merge, см. [[park-pr-vs-run-choice]]). И `run:` берёт НОМЕР PR, а не
id прогона ([[parked-on-run-takes-pr-number]]). Дверь ещё и откажет, если круг на голове ещё идёт
или уже кончился — она считает ВСЕ прогоны на голове, не только круг ревью.
