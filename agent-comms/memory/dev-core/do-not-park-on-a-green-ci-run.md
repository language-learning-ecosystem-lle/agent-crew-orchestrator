Ждёшь зелёного `checks` на своей голове, чтобы повесить метку `review`, — **парк не ставится**.
Ход возвращается себе письмом с `--expects none` (см. [[note-to-self-needs-expects-none]]).

**Почему:** `--parked-on run:N` по двери означает «круг РЕВЬЮ, идущий на PR N, и я жду его ВЕРДИКТА»
(`pr:N` — кнопку merge, см. [[park-pr-vs-run-choice]]). Парк снимается письмом, которое кого-то
двигает. Зелёный `checks` в тред не пишет ничего — значит парк не снялся бы сам, и тред оглох бы
до чужой руки. Это тот же класс, что [[silent-loss-is-the-unraised-turn]].

**Как применять:** доложить «жду CI по #N, голова `SHA`», `--waiting-on <своя роль> --expects none`,
без флагов парка. Следующий такт роли перечитает прогон и повесит метку. Ждать в foreground нельзя
(поллинг запрещён карточкой роли), парк — тоже не тот инструмент.
