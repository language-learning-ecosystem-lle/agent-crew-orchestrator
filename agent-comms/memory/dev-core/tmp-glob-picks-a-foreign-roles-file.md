Переменная `$B=$(mktemp -d)/pr.md` живёт ровно один вызов Bash: shell state между вызовами не
переносится. Восстанавливать путь глобом (`ls /tmp/tmp.*/pr.md | tail -1`) — не восстановление:
`/tmp` общий на ящик, и соседние роли кладут туда файлы с тем же именем. 2026-09-08 так открылся
PR #348 с телом чужого PR (тред `152`, роль `devops`) — поймано только потому, что `pr open`
ПЕЧАТАЕТ прочитанные `thread:`/`role:`, и они не совпали со своими.

**Why:** тот же класс, что [[backup-to-a-bare-tmp-path-restores-a-foreign-file]], но по чтению, а
не по записи: имя файла в общем `/tmp` уникальным не является ни при каком `mktemp -d`, если
каталог из имени выброшен.

**How to apply:** путь из `mktemp -d` не восстанавливать — писать тело и потреблять его в ОДНОМ
вызове Bash (`D=$(mktemp -d -p /tmp) && cat > "$D/m.md" <<'EOF' … && cli … --body-file "$D/m.md"`).
Если файл всё же ищется задним числом — искать содержимым (`grep -l '<свой тред>' /tmp/tmp.*/…`),
а не временем. И сверять вывод двери: `pr open` называет `thread:`/`role:` прочитанного тела —
это единственное, что здесь ловит подмену до глаз ревьюера.
