Хотел написать в текст последовательность из шести символов `\u0000` — Write положил в файл один
байт `\x00`. Дважды в одном треде: сначала в исходнике (`sources.test.ts` пакета запрещает
литеральный NUL — гит считает такой файл бинарным — и уронил `checks` на первой голове PR), потом
в теле письма, где тот же тест уже не сторожит.

**Why:** экранированную последовательность в тексте нельзя набрать напрямую — инструмент её
раскрывает; красноту ловит только тот, у кого есть свой тест на NUL.

**How to apply:** после Write, если в контенте была любая `\uXXXX`-форма, мерить байты
(`python3 -c "print(open(p,'rb').read().count(b'\x00'))"`), а чинить заменой через python
(`d.replace(b'\x00', b'\\\\u0000')`) — Edit по строке с NUL не берётся. `grep -c $'\x00'` на таком
файле молчит вовсе, то есть его тишина доказательством отсутствия НЕ является.
