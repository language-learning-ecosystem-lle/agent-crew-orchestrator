Рабочие места пар зовутся `<роль>@<тред>`, дерева старого образца — просто `<роль>`. Соблазн написать
уборку как «имя без `@` → старый образец → снести» велик, и он **неверен**: в `.worktrees` лежат
пять имён без `@`, и два из них сносить нельзя —

- **`.worktrees/comms` — живой чекаут ПОЧТЫ**, тот самый `--root …/.worktrees/comms/agent-comms`,
  которым ходит каждая роль каждым письмом. По форме пути он ничем не отличается от дерева роли;
- **`pilot-codex`** — роль объявлена `paused`, а не удалена: её дерево вернётся в дело, если john
  снимет паузу.

Снести по этому имени можно только `curator`, `dev-core`, `devops` (замер 17.09, тред 218: 187M на
троих).

Это частный случай общего [[guard-that-infers-identity-from-a-path-fails-open]]: дверь, опознающая
предмет по ФОРМЕ пути, ошибается ровно там, где формы совпали, а предметы разные. Личность дерева
берут из конфига (кто роль, какая активна) и из `git worktree list`, а не из того, есть ли `@` в
имени каталога.
