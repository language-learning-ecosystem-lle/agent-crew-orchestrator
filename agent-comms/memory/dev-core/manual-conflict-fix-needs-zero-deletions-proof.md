Разрешив конфликт в общем реестре (`docs/protocol-reference.md`, `cli.ts`, README), НЕ верить
снятым маркерам: мерить `git diff --cached --stat <база>` и требовать **ноль удалений**, если
предмет только дописывает. Само разрешение собирать механически, а не руками:
`git show <база>:<файл> > <файл>` + приписать блок, добавленный одобренной головой, затем `cmp`
этого блока против `git show <одобренная голова> -- <файл> | grep '^+'`.

**Why:** 2026-09-03, тред `074`, #202. Разрешил по маркерам: сторону `HEAD` оставил, сторону PR
приписал. Маркеры сняты, файл читается, тесты его не касаются — и при этом дифф показал
`39 insertions, 47 deletions`: 47 удалений были целым разделом, который база получила из #216
(тред `052`). Ручной осмотр дефект пропустил; поймал только дифф против базы.

**How to apply:** дорого не «разрешить конфликт», а доказать, что разрешение ничего не съело, и
доказательство обязано быть машинным. Заодно перед push перемерить `git rev-parse origin/main`:
в тот же ход вершина уехала за ~40 секунд, что заняли фетч, чекаут, cherry-pick и разбор одного
конфликта, — перебазировку пришлось начать заново (класс [[stale-pr-may-be-superseded]],
дом — тред `093-registry-tail-race`).
