Греп по ПОЛНОЙ форме указателя (`218-orphan-service-branches-and-dead-worktrees`) даёт ноль при
живом дефекте: голый номер в строке (`dead by the criterion of 218`) он не ловит, а README,
пересказывающий СТАРОЕ поведение указателя, не ловит и подавно.

**Why:** условие закрытия треда было сформулировано как греп по полной форме — и прошло бы, хотя
три пользовательские строки и абзац README продолжали называть тред (вердикт ревьюера, #461).
У строки кода потребителей двое — код и проза, её описывающая: [[anchor-move-leaves-the-caption-behind]].

**How to apply:** мерить обе формы (`218-orphan` И `\b218\b`) плюс греп по докам; чинить КЛАСС
целиком, включая предсуществующие строки, и называть это расширением диффа в теле PR — половина
класса читается следующим читателем как правило. Строка лога, прочитанная через год, обязана нести
смысл сама: раскрывать критерий целиком либо называть НОРМУ, а не тред, который закроется.
