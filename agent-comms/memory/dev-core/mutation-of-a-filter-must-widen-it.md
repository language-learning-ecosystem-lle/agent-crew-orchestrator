Когда покрываемый код — ОДИН фильтр, выражающий критерий («берём только `dead`»), мутация для
доказательства теста (см. [[new-test-must-be-proven-by-mutation]]) обязана быть РАСШИРЯЮЩЕЙ:
`=== "dead"` → `!== "not-a-pair"`. Замер 17.09 (тред 218, П-2): расширение покрасило 4 случая из 5,
включая «брать нечего» и «залоченное стоит»; сужение (`&& false`) покрасило бы ровно один — тот, где
что-то ДОЛЖНО быть взято — и ничего не сказало бы о том, меряют ли тесты запреты.

**Why:** у фильтра два класса ошибок — «не взял должное» и «взял запрещённое». Сужающая мутация
проверяет только первый, а дорого стоит именно второй.

**How to apply:** доказывая набор тестов над критерием-фильтром, мутируй его в сторону БОЛЬШЕГО
множества и считай, сколько случаев покраснело; один покрасневший случай на расширении = тесты
меряют наличие результата, а не критерий. Мутацию снимать точечной правкой, не
[[mutation-probe-must-not-be-undone-by-checkout]].
