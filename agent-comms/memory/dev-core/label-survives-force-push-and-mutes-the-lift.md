Перебазировал PR с уже висящей меткой `review` — метка осталась на новой голове. Снимать её надо
НЕ «когда дойдут руки», а ДО того, как `checks` на новой голове позеленеют.

**Why:** круг ревью поднимает СОБЫТИЕ навешивания метки, а `synchronize` в триггере нет — значит push
круга не поднимает. А единственный звонок, который в этом месте зовёт автора, объявлен узко: зелёный
`checks` на PR, у которого метки `review` ЕЩЁ НЕТ (R27, исключение класса-следа). PR с УЖЕ стоящей
меткой уведомитель считает «круг идёт, действия у автора нет» и молчит. Сходится замок: круга нет
(события не было), звонка нет (метка стоит) — [[silent-loss-is-the-unraised-turn]] в чистом виде, и
ловится он только чужой рукой.

**How to apply:** сразу после `push --force-with-lease` по PR с меткой — `gh pr edit N --remove-label
review`, и только потом смотреть прогон. Порядок «сначала снять, потом ждать зелень» — не аккуратность,
а условие собственного подъёма. Смежное: [[green-letter-does-not-mean-still-mergeable]],
[[do-not-park-on-a-green-ci-run]].
