Замер класса «пакет называет потребителя» (тред `064-forget-the-consumer`) по маркерам
`LLE|language-learning|dev-mobile|dev-speech|mobile` дважды дал ложное «класс закрыт»:
все эти маркеры — ИМЕНА РОЛЕЙ И ДОМОВ, а в пакете жил **путь чужого приложения**
`apps/pronunciation-service` — 53 строки в 14 файлах (фикстуры схемы, значения в тестах,
док-комментарии продуктового кода `roles/zones.ts` и `cli.ts`).

Плюс отдельная ловушка грепа: **`grep -E 'LLE'` без границ слова срабатывает на английском
`CALLED` (CA-LLE-D)** — в `packages/**` таких десятков, шум прячет сигнал. Нужен `\bLLE\b`.

**Why:** переименование ролей (#194: `dev-speech` → `dev-acme`) оставляет путь на СОСЕДНЕЙ
строке нетронутым — и греп по именам ролей после такого переименования пуст, хотя класс стоит.
Маркерный набор пережил предмет, который мерил.

**How to apply:** прежде чем сказать «класс закрыт по замеру», выписать зоны/пути из ЖИВОГО
`agent-protocol.json` и убедиться, что найденный путь там не встречается — если путь есть только
внутри `packages/**` и нет ни в конфиге, ни в `docs/**`, это чужой дом, а не общий пример.
Греп по именам — только дополнение к грепу по путям. Связано: [[label-follows-base-note-not-clean]].
