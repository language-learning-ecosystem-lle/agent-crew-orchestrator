`checkWorkspacePackage` возвращает `{ok: true}` немедленно, когда `reference === undefined`, а
`reference` — это `<главный чекаут>/node_modules/agent-protocol/package.json`. В **собственном**
контуре протокола этого пути НЕТ и по устройству быть не может (пакет и есть репозиторий, сессии
гоняют его из исходников). Значит `staleBuild` здесь не выставляется ни разу, и всё, что висит на
этой ветке отказа, в этом репозитории **недостижимо**.

**Why:** класс «дерево отстало от ящика» — полевой, но все его случаи случились в контуре-ПОТРЕБИТЕЛЕ,
где главный чекаут ставит пакет по пину. Планировать здесь живую приёмку такого дефекта — значит
назначить шаг, который не исполнится, и обнаружить это после того, как работа уже поехала.

**How to apply:** прежде чем обещать полевое наблюдение дефекта версии, мерить оракулом: сухой
`orchestrator run --ref <ref> --role <кто-то> --thread <тред>` печатает строку `package — …` только
когда сравнение СОСТОЯЛОСЬ. Нет строки — двери нет. Второй дефект (`!dependencies.installed`, тред
161) отказом не является вовсе: он идёт нотой `dependencies — …` и родителя не убивает, поэтому
подменить им проверку ветки `staleBuild` нельзя. Приёмку такого класса нести к curator как вопрос
границы контура — [[contour-ground-check-needs-tmp]], [[dry-run-is-a-free-oracle-on-the-ceilings]].
