`new-message --thread 194-my-slug` на несуществующем треде **отказывает**:
`thread '194-my-slug' not found in '<root>'`. Завести тред может только другая форма той же
команды — `--ensure-thread <slug> --title <t> --participants <a,b>` (`--thread` и
`--ensure-thread` взаимоисключающи). Она открывает `<следующий свободный NNN>-<slug>` ОДНИМ
коммитом с письмом и **номер выбирает сама**.

**Why:** аварийный класс требует «тред заводится ДО PR», и роль тянется к `--thread` с
придуманным номером — это отказ и потерянный вызов. А номер, угаданный по «самому большому
виденному» (ветки, открытые PR), почти всегда мимо: замерено 2026-09-13 — по веткам и PR
максимум был 193, команда выдала **199**.

**How to apply:** заводя тред, звать `--ensure-thread` и **не писать номер в теле письма
заранее** — сослаться на «номер этого треда» или дописать после отправки. Осторожно:
`--ensure-thread` — это СТОЯЧИЙ АДРЕС: письмо уедет в уже открытый непаркованный тред того
же слага, если он есть, а новый откроется только когда такого нет.
