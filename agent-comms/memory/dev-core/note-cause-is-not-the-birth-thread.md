Механизм гашения (`memory-cause.ts`, тред `090-what-kills-a-note`) читает `thread:` во фронтматтере
как повод: тред закрыт — заметка удаляется вместе со своей строкой в `MEMORY.md`, и смерть уезжает в
ветку почты. Поле выглядит как «откуда заметка», и это ровно неверное чтение.

**Why:** померено 2026-09-03 на своей куче — из 36 заметок 16 упоминают тред в тексте, и **8
упоминают ЗАКРЫТЫЙ** (`075`, `060`, `088`, `022`, `071`, `089`, `116`). Ни одна из восьми короткой не
является: «сначала приземляй вызываемое, потом вызывающее», «число проверок перемеряется», «письмо
себе — только `--expects none`» верны и сейчас. Пометь их тредом рождения — 8 из 36 (22 %) кучи
погасли бы на следующем подъёме, то есть ровно та потеря, из-за которой john отверг срок жизни
заметки.

**How to apply:** перед тем как вписать `thread:`, задать один вопрос: «предмет закрыт — заметка
стала бесполезной?». Да → повод, заметка короткая. Нет → **поля не писать вовсе**; сорт выводится из
наличия повода, и отсутствие поля и есть объявление «долгая». Упоминание треда в ТЕЛЕ поводом не
является и безопасно (тест в `memory-cause.test.ts`) — «где узнали» пишется прозой, «пока открыт» —
фронтматтером. Куча из долгих заметок сортом не уменьшается: потолок оглавления для неё гасится
только явным действием с называнием основания. Связано: [[note-sort-has-no-subscribers-yet]].
