Совпадение числа тестов доказательством не является само по себе (см. [[commutative-merge-is-not-proof-nothing-was-eaten]]) — но становится им, если число ПРЕДСКАЗАНО до прогона: сумма «база + каждый слагаемый пакет» (`3696 + 1 + 8 + 8 = 3713`), и любой другой итог объявлен находкой заранее. Тогда попадание в него закрывает сразу обе стороны add/add-ребейза: ни один чужой тест не съеден, ни один свой не задвоен.

**Why:** сверенное ПОСЛЕ число подгоняется задним числом под что угодно; предсказанное — это ставка, которую замер либо оплачивает, либо ломает. 2026-09-06 (тред 141, #310 на базе #309) curator выдала прогноз 3713 письмом до моего ребейза; локальная сюита дала ровно 3713 — и это стоило дешевле поштучного диффа имён через `vitest list` (см. [[attribute-a-test-count-delta-with-vitest-list]]).

**How to apply:** перед ребейзом с пересечением путей выписать арифметику слагаемых и назвать ожидаемый итог В ПИСЬМЕ, до прогона. Сошлось — доказательство; разошлось — [[attribute-a-test-count-delta-with-vitest-list]] называет, что именно уехало. Само число всё равно мерить своей рукой ([[test-counts-must-be-remeasured]]), а нулевые удаления в общем файле проверять отдельно ([[manual-conflict-fix-needs-zero-deletions-proof]]).
