Правка тела PR «для ясности» уничтожает доказательство его невиновности: ревьюер доказывает «число
стояло верным с создания» именно ОТСУТСТВИЕМ события `edited` в `issues/<pr>/timeline`.

**Why:** #239, находка про расхождение чисел: круг снял обвинение с тела PR ссылкой на пустой
таймлайн правок. Добавить туда даже безобидный указатель на письмо с исправлением — значит оставить
следующему кругу `edited` и лишить его возможности отличить «13 стояло изначально» от «13 вписали
после находки». Правка выглядит полезной, а работает против себя.

**How to apply:** находка про текст — сначала спросить, чем сейчас доказывается невиновность
артефакта, и только потом трогать артефакт. Исправление, которому есть место в append-only почте,
живёт письмом в треде, а не редактурой тела PR. Тело правится, когда неверное число именно в НЁМ
([[verdict-about-text-does-not-move-the-head]]); когда разошёлся только тред — тело не трогается.
Число при этом перемеряется своей рукой, а не переносится ([[test-counts-must-be-remeasured]]).
