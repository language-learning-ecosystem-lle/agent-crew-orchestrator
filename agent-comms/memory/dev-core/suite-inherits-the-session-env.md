Процессный тест наследует среду ТВОЕЙ сессии, включая `AGENT_PROTOCOL_WORKER`,
`AGENT_PROTOCOL_LEASE_DEADLINE`, `AGENT_PROTOCOL_SESSION_FILE`, `AGENT_PROTOCOL_RAISED_AT`.
Дверь, которая по такой переменной судит «меня породил оркестратор», локально видит
ДА, а в CI — НЕТ, и цвет теста зависит от того, чья рука его гоняет.

Замерено 06.09.2026: новый `orchestrator thaw` отказывает поднятой сессии по
`AGENT_PROTOCOL_WORKER`; первый прогон его процессного теста покраснел ЦЕЛИКОМ — все
пять случаев получили этот отказ, включая те, что про совсем другое.

**Почему:** `spawnSync(..., { env: { ...process.env } })` — обычная форма харнесса, и
она тащит контракт запуска в ребёнка.

**Как применять:** харнесс процессного теста ЯВНО вычищает переменную, которую судит
дверь (`const { AGENT_PROTOCOL_WORKER: _w, ...clean } = process.env`), и ставит её
обратно только в том случае, который про неё. Обратная сторона — [[green-on-the-box-may-lean-on-the-box-token]]:
там дверь без кредитала деградирует в другую сторону; здесь среда, наоборот, ДОБАВЛЯЕТ
роли то, чего у человека нет. Оба лечатся одним: перед заводом в CI прогнать проверку с
той средой, в которой её будут гонять.
