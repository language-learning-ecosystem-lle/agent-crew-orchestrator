`origin/main` в рабочем дереве роли может уехать **посреди твоей работы**: рефы у дерева роли и у
демона общие, и его `fetch` двигает ветку без твоего участия. Замерено 13.09.2026 на #383: между
`git show origin/main:<файл> > снимок` и сверкой прошло несколько минут, база уехала на новый коммит,
и склейка собралась из ревизии, которой на базе уже нет.

**Why:** снимок портится молча — `git show` по ИМЕНИ ветки не фиксирует ничего, а ручное разрешение
конфликта стоит на том, что три ревизии взяты из одного мгновения.

**How to apply:** ревизии для ручной склейки вынимать по неподвижному имени — `MERGE_HEAD` и полные
SHA, а не `origin/main`. И всегда печатать сверку: ненулевые удаления там, где обе стороны только
дописывают в хвост, — единственный признак этой порчи (ожидалось `30/0`, напечаталось `27/44`).
