`[--journal <p>]` в справке `orchestrator thaw` читается как «можно опустить», но опустить нельзя:
фолбэк идёт в `pathsFrom` → `configFrom`, а тот делает `required(argv, "--ref")` — и `--ref` в
argv-спеке команды (`usage.ts`) нет, так что дверь отказывает по нему как по неизвестному флагу.
Замкнутый круг: без флага «`--ref` не задан», с флагом «`--ref` — unknown flag».

**Why:** сюита команды была зелёной (5 случаев), потому что КАЖДЫЙ из них передавал `--journal`
явно. Ни один тест не гонял объявленную форму по умолчанию, и дефект дожил до мержа — нашёлся
только когда сквозной тест попробовал вызвать команду так, как её наберёт оператор.

**How to apply:** сдавая команду с необязательным флагом, прогнать её БЕЗ него хотя бы раз — и
сверить два списка: флаги, которых требует резолвер по умолчанию, против флагов, которые принимает
argv-спека. Общая форма шире `thaw`: любая пара «умолчание в одном месте — allowlist в другом»
проверяется вызовом, а не чтением. Родня: [[door-defects-hide-in-process-tests]],
[[documented-command-must-run-from-the-role-workplace]], [[new-test-must-be-proven-by-mutation]].
