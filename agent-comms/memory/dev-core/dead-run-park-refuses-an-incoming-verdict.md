Доставка вердикта (`.github/scripts/review-delivery.sh`) обязана сказать о стоящем парке:
`park_probe` вынимает его значение из текста двери, `park_flags` (`:323`) строит флаг по правилу из
трёх случаев — свой круг → `--park-lifted`, ЧУЖОЙ парк → `--parked-on <то же значение>`, парка нет →
без флагов. Ветви «чужой парк, чьё основание дверь объявила МЁРТВЫМ» в правиле НЕТ, и попадание в
неё — не пауза, а потеря письма: `--parked-on run:N` дверь отказывает («every run on head <sha> of
PR #N has ALREADY FINISHED … the lift only ever looks forward»), а `--park-lifted` на чужой парк
запрещён шапкой самого правила («чужой парк снимать нечем, и врать о нём нельзя»).

**Why:** замерено 2026-09-12 (тред `180-notifier-down`, прогон `34703884006`): парк `run:374`
объявлен 16:01:15Z, `checks` по #374 закрылся success 16:08:47Z — основание умерло, — доставка
вердикта по ДРУГОМУ PR (#373) пошла 16:17:02Z и была отказана в 16:17:03Z. Вердикт `approve` погиб
целиком; спасло его только то, что текст дублируется комментом в PR и пришла рука. Красным прогон
делает шаг «Итог доставок», хотя вердикт вынесен и два канала из трёх доехали. Письмо `github` об
исходе `checks` парк не снимает и даже не называет — машинный писатель (`wake.mode === 'event'`)
освобождён от этой обязанности, см. [[run-park-under-checks-has-no-lifter]].

**Класс требует ЧУЖОГО парка, и это замерено отдельно.** 2026-09-13, тред 189, прогон `34759280002`:
на адресате стоял МОЙ парк `run:384`, круг шёл по PR #384 — курьер напечатал «стои́т парк 'run:384' —
письмо идёт с '--park-lifted run:384'» и письмо доехало (27 вставок в тред). То есть `N` в `run:N` —
номер PR, и когда он совпадает с PR круга, правило из трёх случаев читает парк как «за ЭТИМ кругом» и
снимает его САМО. Дефект поднимается только на парке, чей `N` — ДРУГОЙ PR (случай #374 против #373
выше). Красным прогон при этом всё равно был — но по другой причине: вердикта не существовало вовсе
(429), а не потому, что доставку отказала дверь.

**How to apply:** увидел красный круг ревью с живым вердиктом в комменте PR — не перезапускай круг
(это новый прогон и новый вердикт): сними текст `gh pr view <pr> --json comments --jq
'.comments[0].body'` и донеси письмом руками. Пишешь в тред с мёртвым парком своей рукой — флаг
`--park-lifted run:N` (дверь сама предлагает эту форму третьей), а не `--parked-on`. И читай ПРИЧИНУ
отказа в логе, а не в эскалации: эскалация ревьюера назвала этот случай «дверь права, отказывая
письму рядом с парком», тогда как письмо рядом с парком как раз разрешено и именно так и писалось —
отказала вторая дверь, дверь ОСНОВАНИЯ. См. [[do-not-park-on-a-green-ci-run]],
[[own-park-can-kill-an-incoming-verdict]], [[letter-into-a-standing-park-must-name-it]].
