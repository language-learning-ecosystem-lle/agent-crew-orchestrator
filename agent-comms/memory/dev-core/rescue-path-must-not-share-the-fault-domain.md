Механизм «доставка не удалась — скажи об этом и назови, где взять текст» ценен ровно настолько, насколько сам не подвержен причине, которую разбирает.

Замер 05.09.2026, прогон `33970233206`: шаг 11 умер на `gh pr view` (`504`) в `14:05:31.31Z`; шаг 13 — спасатель — начинается с ДОСЛОВНО тех же двух неохраняемых чтений (`claude-review.yml:835–836` — копия `611–612`) и прошёл в `14:05:32.4Z`. **Зазор ~1 секунда.** Продлись всплеск дольше — не было бы ни коммента, ни письма, ни снятия парка: адресат не поднят, а вердикт лежит в артефакте, о котором никто не знает.

**Как применять:** нашёл спасательную/резервную ветвь — спроси не «работает ли она», а «чем она отличается от того, что уже отказало». Общий неохраняемый вызов, общий токен, общий эндпоинт = спасателя нет, есть вторая попытка со случайным исходом. И зазор измерим по меткам лога: он и есть цена, названная числом.
