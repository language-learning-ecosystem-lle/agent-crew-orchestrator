Приёмка «дифф трогает только комментарии, поведение не менялось» снимается **разбором обеих
ревизий**, а не формой строк:

```
git show <база>:<путь> > /tmp/base.yml
python3 -c "import yaml;print(yaml.safe_load(open('/tmp/base.yml'))==yaml.safe_load(open('<путь>')))"
```

**Why:** счётчик «несомментных изменённых строк» (фильтр `^[+-]` минус `^[+-]\s*#`) — прибор о
ТЕКСТЕ, а закрывают им утверждение о ПОВЕДЕНИИ. Совпадают они только там, где `#` действительно
означает комментарий, и это свойство МЕСТА в файле. Внутри блочного скаляра (`run: |`, `script: |`)
строка с `#` — СОДЕРЖИМОЕ скаляра, поэтому чистое ДОБАВЛЕНИЕ таких строк проходит фильтр целиком.
Замерено зондом 2026-09-13 (тред `191`): `#`-строка, дописанная внутрь `script: |`, даёт счётчику
**0**, а разобранный YAML при этом РАЗЛИЧАЕТСЯ — `script` становится
`"# пояснение\ncore.info('hi')\n"`, для `actions/github-script` это ошибка JS, то есть красный шаг
из диффа, выглядящего чистой прозой. Обратный случай (исполняемая строка закомментирована) счётчик
ловит — удаляемая строка приходит несомментной, — так что слепое пятно ровно одно и именно у
ДОБАВЛЕНИЙ.

**How to apply:** просят приёмку «только комментарий» — снимай ОБА прибора и клади в тред оба.
Сравнивать надо сами структуры, а не `json.dumps(..., sort_keys=True)`: у воркфлоу ключ `on` YAML
разбирает в булево `True`, и сортировка ключей падает на `'<' not supported between instances of
'bool' and 'str'`. `--numstat` рядом закрывает вторую половину («соседние абзацы не переписаны») —
удалений ноль доказывается арифметикой, а не глазом ([[manual-conflict-fix-needs-zero-deletions-proof]]).
