2026-09-06: в доставленном письме я назвал «#286 лёг за **82 секунды** до моего сквоша». Настоящий
разрыв — **17 минут 33 секунды** (#286 `mergedAt` 11:58:21Z, #292 — 12:15:54Z). Число я взял из
`gh run list --branch main`: на голове `b59029c6` там стоял прогон с `createdAt` 12:15:35Z, и я
прочёл его как «вот когда эта голова появилась».

**Why:** на одной голове прогоны заводятся не только push'ем и не только сразу. Тот 12:15:35Z был
`Notifier Watch` — он поднялся по СВОЕМУ поводу через 17 минут после посадки коммита. Список
прогонов упорядочен по времени ПРОГОНОВ, а не по времени голов, поэтому соседние строки выглядят
как соседние посадки. Тот же класс, что [[release-tag-number-does-not-say-what-it-carries]]: артефакт
рядом с коммитом не датирует коммит и не говорит, что в нём.

**How to apply:** время посадки спрашивать у самой цели, одной командой:
`gh pr view <N> -R <repo> --json mergedAt,mergeCommit`. Без номера PR — `git log -1 --format=%cI <sha>`
(дата коммиттера сквоша и есть момент кнопки). `createdAt` прогона годится ровно на одно: датировать
сам прогон. И если разрыв между двумя посадками несёт смысл в письме (а он его нёс — «пару никто не
мерил»), то это ЧИСЛО ЗАМЕРА, и меряется оно до отправки, а не после.
