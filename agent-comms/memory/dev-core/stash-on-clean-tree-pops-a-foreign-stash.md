Приём «`git stash` → прогнать базовый замер → `git stash pop`» на ЧИСТОМ дереве ломается:
stash не создаётся, а `pop` достаёт `stash@{0}` — лежалый wip умершей сессии другой ветки
(`git stash list` в этом репозитории держит их несколько), и получается конфликт в чужом файле.

**Почему:** оркестратор выдаёт роли чистое рабочее место, а осиротевшие stash'и от прерванных
сессий живут в общем списке репозитория, не в дереве.

**Как применять:** база меряется ДЕТАЧ-ЧЕКАУТОМ на её SHA (`git checkout -q <base>`), а не
stash'ем. `git checkout main` в воркдереве роли откажет — ветка занята домашним чекаутом,
нужен именно SHA. Если pop всё же случился — файл вернуть из `HEAD`, а чужой stash
проверить в `git stash list`: при конфликте он ОСТАЁТСЯ на месте, терять его нельзя.
