Цену такта не надо оценивать по знакам — она **раскладывается по причинам с точностью 99,4%**:

- у каждого `assistant` в `.orchestrator/sessions/*.jsonl` стоит `usage` = РАЗМЕР КОНТЕКСТА
  (`cache_read + cache_creation`); дельта между соседними обращениями — ровно то, что добавил
  предыдущий шаг. Кусок X токенов на обращении k из N носится (N−k) раз как cache-read;
- сумма таких «ношений» обязана сойтись с измеренным `lease-released.usage.tokens.cacheRead` —
  это встроенная проверка метода, а не украшение;
- **цены моделей не берутся из прайс-листа:** МНК по `costUsd` тактов одной модели даёт
  out/cacheWrite/cacheRead с ошибкой ±$0.009 на такт. Канал `in` в подгонку не брать — вырожден
  (десятки токенов при миллионах прочих), система становится плохо обусловленной и даёт NaN.

Замеренное так 06.09 (`134`): `claude-sonnet-5` дешевле `claude-opus-5[1m]` всего **в 1,6 раза** —
премия за окно 1M съедает разрыв, и «отдать чтение дешёвой модели» экономит куда меньше, чем
кажется по прайс-листу. Считает `scripts/read-cost.mjs`; сосед по жанру — [[prose-cost-script]].
