Прежде чем писать фикстуру на защитную ветвь («X не прочитан», «значения нет»), спроси: КАКИМ
ВХОДОМ до неё вообще доехать. Если отбор элемента и чтение его поля идут по ОДНОМУ ответу и сам
отбор стои́т на этом поле, расхождения между ними данными не построить — фикстура проверит отбор,
а сверка будет зелёной по ложной причине.

**Why:** замерено 15.09 на хвосте глушения (тред 198, PR #448): отбор хвоста — `select(.created_at
> $last_at)`, значит прогон без `created_at` в хвост не попадает НИКОГДА, и фикстура «прогон без
времени» ничего о ветви не говорила.

**How to apply:** доезжать до такой ветви подменой самого предиката в подоболочке сверки
(`predicate() { return 5; }; harness …`), и РЯДОМ ставить сверку, что подмена не протекла в
соседние. Зелёная сверка на недостижимой ветви — не покрытие, а отчёт о другом коде.
