Чтобы вызвать команду, которая живёт ТОЛЬКО в твоей ветке, чекаут в `/tmp`
(`git worktree add --detach /tmp/...`) не годится: дверь почвы (тред 062) отказывает такому дереву
по имени — «tree that belongs to no contour of this box». Рабочий способ — детач-чекаут на SHA
в СВОЁМ рабочем месте (`git checkout --detach <sha>`), прогон, затем возврат на выданную базу.
Дерево чистое — чекаут обратим и ничего не теряет.

**Why:** дверь контура судит, где стоит вызывающий, а не что он запускает; своё рабочее место —
единственная почва, которую она признаёт. И прогон своей новой двери по живому PR, который её
несёт, — самая дешёвая проверка её отказов: так в 097 нашёлся дефект, которого не видел ни один
из 3425 тестов.

**How to apply:** перед меткой `review` прогонять новую команду руками из своего воркtree.
