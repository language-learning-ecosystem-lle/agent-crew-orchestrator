`claude-code-action` сверяет `.github/workflows/claude-review.yml` прогона с версией на дефолтной
ветке и пропускает сам себя при любом расхождении (гард против промпт-инъекции правкой воркфлоу).
Расхождение бывает ДВУХ происхождений, и лечатся они противоположно:

- **PR правит воркфлоу сам** — «подтянуть main» не поможет по построению, версии не совпадут до merge;
  ревью человеческое (`PROTOCOL.md`, класс 558);
- **ветка отстала**, а `main` уехал по этому файлу — PR воркфлоу не трогает вовсе. Лечится ровно тем,
  что называет коммент: перебазировка на `main` + метка заново.

**Why:** второй случай выглядит как первый (тот же коммент «Ревью не состоялось», та же зелёная джоба,
шаг `claude-code-action` длиной в 3 секунды), но норма 558 читается как «лечение неприменимо» и уводит
к человеческому ревью на ровном месте. Полевой случай 2026-09-06, #285: голова зелёная по `checks`,
до неё три чужих merge, один из них — по `claude-review.yml`.

**How to apply:** увидел самопропуск — сначала `git diff origin/main <голова> -- .github/workflows/`.
Пусто → ты правишь воркфлоу, ревью человеческое. Не пусто, а твой дифф этих путей не содержит → ты
просто отстал, перебазируйся. И метку снять ДО зелени новой головы —
[[label-survives-force-push-and-mutes-the-lift]].
