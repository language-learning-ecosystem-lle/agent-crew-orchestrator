`standingParkOf` (`thread/thread.ts`) снимает `run:` парк ровно двумя вещами: полем `park-lifted`
рукой и парой `verdict:`+`pr:N`. Письмо об исходе `checks` не несёт ни того, ни другого —
`.github/workflows/ci-outcome.yml` зовёт `new-message --from github --expects none
[--waiting-on <роль>]`, и всё. Значит парк на `run:N` под `checks` кончается ТОЛЬКО лопнувшим
потолком `RUN_PARK_TTL_SECONDS` (30 мин).

**Why:** замерено по `daemon.log` в треде 187 (2026-09-11) двумя случаями подряд: зелёный `checks`
14:31:25Z → метка 14:55:05Z (23 мин 40 с мёртвого времени); 15:16:57Z → 15:45:06Z (28 мин 09 с).
~52 минуты замороженной пары на одном треде за сутки. Оба подъёма пришли по ветке, написанной для
ПОТЕРЯННОГО прогона, — здоровый ход отчитывается в логе как авария. Вывод (не замер): регрессия
варианта «А» (тред 155, 2026-09-08), снявшего лифт «любое письмо, которое кого-то двигает»;
письмо `ci-outcome` ставит `--waiting-on`, то есть двигает.

**ПОЧИНКА ЭТОГО — НЕ РУКА dev-core, и причина структурная** (перемерено 2026-09-11, тред 188):
письмо об исходе `checks` не несёт в шапке НИ ОДНОГО поля, называющего PR, — номер стои́т только в
ТЕЛЕ, прозой (`✅ **checks по PR #400: success.**`). Это же сказано кодом: `run-park.ts:29` — «the
header of an outcome message names no run». Значит любая форма лифта добавляет заголовок И правит
`.github/workflows/ci-outcome.yml`: новая форма сообщения + док власти, два раза кнопка john.
Третий лифт `run:N`, о котором легко забыть: `merged-pr: N` (`thread.ts:544` и `:560`, обе
половины) — но merge приходит позже вердикта, то есть позже всего, ради чего парковались.

**How to apply:** парк на `run:N` честен, когда ждёшь КРУГ РЕВЬЮ — его вердикт несёт
`verdict:`/`pr:` и снимает парк по адресу. Под `checks` парк платит получасом: либо не парковаться
и принять немедленный подъём, либо принять эти 30 минут сознательно. Цепочку отравленного потолка
разрывает письмо с `park-lifted` и БЕЗ парка — см. [[carrying-a-park-forward-does-not-restart-its-ceiling]];
про требование живого прогона — [[do-not-park-on-a-green-ci-run]].
