`--parked-on run:N` в `new-message` берёт **номер PR**, а не номер прогона CI: дверь идёт
`gh pr view N`. Из строки usage (`<person|pr:N|run:N>`) это не читается — `run:` там про
«парк на круг прогона по этому PR», а не про идентификатор прогона.

**Почему важно:** 2026-08-30, тред `056`, я поставил `run:421` (номер прогона `checks`).
Дверь не нашла PR #421, парк остался непроверенным и снялся бы только по потолку возраста
в 30 минут — то есть пара проснулась бы впустую. Правильно было `run:172` (номер PR).

**Как применять:** паркуясь на свой CI, брать номер PR; проверка удалась, если дверь
отвечает «waits for a run that is still running (N of M on head …)». Если в треде уже стоит
чужой/свой парк, новое письмо обязано его назвать: `--park-lifted run:<старый>` вместе с
`--parked-on run:<новый>`, иначе дверь откажет по имени.
