Тред-**стоячий адрес** (приёмная целого класса, напр. `076-main-red-alarm` — «красный main без PR») на `--parked-on pr:N` НЕ паркуется, даже когда парк формально легален и такт за тактом поднимается впустую.

**Why:** парк замораживает тред целиком. Письмо о НОВОЙ, другой аварии того же класса ляжет в приёмную и не поднимет никого; `pr:`-парки при этом не стареют (`--run-park-ttl` есть только у `run:`) и курьер о них молчит — значит срок глухоты не ограничен ничем. Цена пустого такта — одна команда; цена парка — незамеченная вторая авария.

**How to apply:** перед парком спросить «это инцидент или приёмная класса?» — паркуют инциденты. В приёмной вместо парка отпускать ход в `—` и каждый такт одной командой проверять, та ли причина: `gh run view <id> --json jobs -q '.jobs[].steps[] | select(.conclusion=="failure") | .name'` — одна строка значит «причина прежняя, §-ы прошлого письма в силе, передавай ход». Выбор `pr:` vs `run:` — [[park-pr-vs-run-choice]]; про то, что `pr:`-парк снимается только письмом с `merged-pr: N` (его шлёт `merge-notify.yml`), а не самим мержем в GitHub — [[parked-on-run-takes-pr-number]].
