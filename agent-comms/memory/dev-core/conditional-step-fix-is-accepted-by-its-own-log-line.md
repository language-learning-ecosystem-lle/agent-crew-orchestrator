«Шага в артефактах нет вовсе» — не приёмка: условный шаг из перечня не исчезает, он стои́т
`skipped`, и стои́т им у ОБЕИХ ревизий кода. Приёмка — текст, который печатает только новая ветвь.

**Why:** перечень шагов это форма `.yml`, одинаковая до и после правки; замер по нему не различает
ревизии вовсе, а выглядит как проверка.

**How to apply:** до правки и после — выписать две разные строки причины и грепать лог:
`gh run view <ID> --log | grep -a '<префикс строки>'`. Пример 14.09 (#417): было
`limit: переезда нет — в транскрипте … признака лимита нет`, стало
`limit: переезда нет — основной шаг круга отработал успешно (outcome=success)`. Ту же подстроку
пиньить состоянием сюиты, чтобы полевой замер и тест сверяли ОДНУ строку.
