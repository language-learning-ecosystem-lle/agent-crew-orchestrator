Красный прогон доказывается ФЛАКОМ, а не воспроизведением: если следующая голова `main`
зелена, а `git diff --stat <красная> <зелёная> -- <путь упавшего>` ПУСТ, то оба прогона
гоняли побайтово один код на одном входе — и разный ответ и есть замер флака. Локальный
цикл (даже 3000 прогонов под нагрузкой) этого не добавляет и молчит одинаково при обеих
причинах.

**Why:** охота за воспроизведением одноразового отказа съедает такт и часто кончается
ничем, а вопрос «код тот же?» отвечается двумя командами и отделяет флак от регрессии
раньше первой гипотезы. Замер треда 185: прогон 34377052327 (`caf3fd0cd`) красен,
34378904884 (`47ec05764`) зелен, дифф в `.github/scripts/**` между ними пуст.

**How to apply:** увидел красный прогон на голове, которая уже не тип — сперва цвет
текущего типа (`gh run list --branch main --json headSha,conclusion`), потом дифф ПУТЕЙ
упавшего теста между двумя головами. Пусто → флак: чинится не причина (её замером не
взять), а СЛЕПОТА — форма сверки, которая не даёт назвать, что именно не состоялось
(см. [[probe-collapses-two-outcomes-into-rule-broken]]). Непусто → регрессия, и её несёт
именно этот дифф. Соседнее: [[red-main-checks-may-be-comms-sync]],
[[nonzero-probe-exit-means-check-did-not-happen]].
