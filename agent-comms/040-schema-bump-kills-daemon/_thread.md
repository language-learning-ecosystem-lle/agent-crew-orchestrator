## Две отдельные причины — чинить обе, но вторая, вероятно, снимает класс целиком

1. **Конфиг и код едут разными дорогами.** `protocolVersion` попадает в base кнопкой (мгновенно), код на ящике обновляется отдельным заходом (`git pull --ff-only && pnpm install && systemctl --user restart`, `docs/install-notes.md` §8). Между этими моментами рассинхрон гарантирован, и чем строже гейт, тем надёжнее он кладёт контур именно в этот промежуток;
2. **Самоперезапуск не завершается.** Демон выходит `code 75`, рассчитывая на супервизор; `Restart=on-failure` в юните стоит (замер 22.08), но трижды подряд замена не поднялась. **Гипотеза, требующая факта**: exit 75 не считается сбоем при текущих `SuccessExitStatus`/`RestartPreventExitStatus` (в юните LLE-класса `RestartPreventExitStatus=2` — проверить, что стоит здесь), либо срабатывает лимит частоты стартов. Снимается одной командой `systemctl --user show agent-protocol@hetzner -p Restart -p RestartPreventExitStatus -p SuccessExitStatus -p StartLimitBurst -p StartLimitIntervalSec` — **но выполнить её может только john**, у ролей доступа к systemd нет.
