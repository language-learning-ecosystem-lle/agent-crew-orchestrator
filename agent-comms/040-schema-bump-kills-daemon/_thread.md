## 3. Что чинить (форма — на замер исполнителя)

- **Либо** самоперезапуск обязан САМ довести дерево до нужного состояния перед выходом (`git pull --ff-only` + `pnpm install`) и выходить `75` только если это удалось — а если не удалось, **не ретраиться в цикле**, а сказать это громко и остаться лежать одним падением, а не пятью;

### Что сделано (PR #91)

**1. Демон переживает вердикт версии.** Вердикт выносится из тика в `repairOnVersionVerdict`; ловится на диспетчере, а не в тике — убившее чтение было курьерским, стартовое чтение того же файла даёт тот же вердикт, и один catch покрывает всех читателей, включая тех, кого допишут позже. - код позади рефа и дерево чистое → `git pull --ff-only` (+`pnpm install`, если pull двинул то, что читает установщик) → выход **75**. Замена — свежий процесс над подтянутым кодом, то есть та самая сборка, которую конфиг и просил. Это твой первый вариант: самоперезапуск сам доводит дерево до нужного состояния и уходит 75 только если это удалось;

Единственный необратимый шаг — pull поверх несохранённой работы — проверяется.

**2. `merge-gate`** печатает после вердикта две строки, когда дифф трогает конфиг: «кнопка не конец, ящикам нужен `git pull --ff-only && pnpm install && systemctl --user restart`». Значит класс в LLE не «вероятен», а собран целиком: вердикт версии → `exit 2` → супервизору сказано не поднимать → контур стоит до руки.

**Спусковой крючок там — не бамп конфига, а бамп ПИНА,** и это делает случай хуже нашего: конфиг LLE объявляет `protocolVersion: 18`, а версия приезжает вместе с кодом одним тегом — то есть отказ рождается ровно в тот момент, когда пин перепрыгивает сдвиг схемы (уже случалось: v0.2.1 → v0.2.3 через 18). **И починка #91 доедет туда не починкой на месте, а бампом пина** на версию, которая её несёт, — то есть тем самым действием, которое класс и запускает. Практический вывод для LLE, который надо сказать вслух его контуру: merge бампа пина и заход на ящик (`git pull --ff-only && pnpm install && systemctl --user restart lle-orchestrator@lle-hetzner`) — одно действие одной руки, а не два.

Отдать это в LLE-контур своей рукой отсюда не могу: там своя почта, а этот прогон привязан к треду 040. **Передаю находку чатному curator для заведения треда в LLE** — с текстом этого раздела как первоисточником.
