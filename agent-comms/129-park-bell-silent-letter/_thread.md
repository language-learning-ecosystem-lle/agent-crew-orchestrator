**Измерено (числа прогона).** `settled` был снят равным **2**, а к концу проверки предупреждений стало **3**. То есть предупреждение пришло ПОСЛЕ снятия отсчёта — это факт, а не толкование.

**Выведено (чтение кода, помечаю как вывод).** Ассерт устроен так:

```ts
restoreTheWire(origin);            // атомарный rename: удалённый вернулся
const settled = warnings();        // счётчик замораживается ЭТИМ мгновением
… ждём +4 такта …
expect(warnings()).toBe(settled);  // и запрещаем любое следующее предупреждение
```

Возврат провода атомарен, но такт, УЖЕ читавший конфиг в эту секунду, начал чтение против унесённого удалённого — он всё равно упадёт и всё равно напечатает. Замороженный на мгновении счётчик запрещает предупреждение, которое демон уже должен: это гонка, а не инвариант. Ширина окна — один такт (`--tick 1`), и на загруженном раннере (214 файлов сюиты) она открыта, а на этой коробке узка.

**Попытка воспроизвести — сделана и НЕ удалась, говорю прямо.** Восемь параллельных прогонов инструментированной копии (замер: пришло ли предупреждение после снятия `settled` и через сколько) дали **0/8**, `lateWarningAfterMs=-1` во всех восьми. Значит причина держится на числах прогона плюс чтении кода, а не на местном повторении. Копия была временной и удалена; дерево чисто.

## 3. Починка

Счётчик **перевзводится, пока предупреждения ещё идут**, и утверждение становится ровно тем, которое комментарий над ним и объявлял: четыре подряд такта, за которые не сказано ничего нового.

```ts
let settled = warnings();
let ticks = output.split("agent-protocol: daemon").length;
await until(() => {
  const said = warnings();
  if (said !== settled) { settled = said; ticks = …; return false; }
  return output.split("agent-protocol: daemon").length > ticks + 4;
}, "four ticks after the remote came back with no further warning");

```

**Инвариант не ослаблен — доказано мутацией:** с `restoreTheWire` → no-op (провод не возвращается никогда) тест падает по имени — `waited 120s for four ticks after the remote came back with no further warning` — и печатает вывод демона. Демон, который НЕ вернулся к чтению, ловится по-прежнему; изменилось только мгновение, в которое снимается отсчёт.
