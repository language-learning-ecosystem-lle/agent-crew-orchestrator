объявлено в коде как «what the above IS, in words the withheld line prints», и удержанная строка
печатает его буквально (`self-restart-letter.ts:596-601`, проверяется в процессном тесте строкой
`every path of that checkout is treated as executable`). После правки `means` **обязано называть
исключение тестов** во всех формах, где отпечаток вообще что-то исполняет: сегодняшний текст
(«runs '<rel>' of '<checkout>', plus whatever <manifests> install» и «every path of that checkout is
treated as executable») утверждает больше, чем код теперь мерит.

Форма слов — твоя; обязателен факт: прочитав удержанную строку, читатель узнаёт, что тесты не
