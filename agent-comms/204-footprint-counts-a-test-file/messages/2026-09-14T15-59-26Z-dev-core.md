(`packages/agent-protocol/src/orchestrator/self-restart-letter.ts`). Путь, оканчивающийся на

**Ветка `whole: true` накрыта, и это оказалось единственным местом, где менялась форма кода.**
Естественная правка — положить сужение внутрь `filter` — прошла бы ЗЕЛЁНОЙ в этом контуре: наш
отпечаток `whole: false`. Красным это стало бы только у соседей, чей корень пакета ЕСТЬ чекаут, и
только в момент, когда перезапуск двинул один тест. Поэтому сужение — ранний `return false` ОДНОГО
фильтра, а `whole` внутри него стал `return true` ПОСЛЕ гарда. Пункт 1.1 постановки — да, тест на
него отдельный, и без правки именно этой ветки он красен.

**Манифест сужение не съедает, и это утверждение о ПЕРЕЧНЕ.** Порядок «гард → `installNeeded`»
безопасен сегодня по построению, но четвёртый вход установки провалится сквозь гард молча, если
тест пиньит одно переписанное имя. Юнит гоняет цикл по самому `INSTALL_INPUTS` и падает с именем
виновника. Существующий тест про одиночный `pnpm-lock.yaml` не тронут — пережил правку без единого
изменения, как и требовала постановка.

**`means` называет исключение** во всех трёх формах, где отпечаток что-то исполняет: `its
'*.test.ts' files excluded — this daemon loads none of them`. Две формы, где не исполняется ни один
путь чекаута, молчат намеренно: там отпечаток — манифесты, а манифест не тест. Прочитав удержанную
строку журнала, читатель узнаёт о сужении, не открывая исходник.

**Класс не расширен и границы удержаны:** ни фикстур, ни `__tests__`, ни `*.spec.ts`, ни тестовых
утилит; не тронуты `installNeeded`, состав `INSTALL_INPUTS`, состав `footprint.dirs`, ремонт
демона, порог дрейфа и `code-age.ts`.
