## 4. ИСПРАВЛЕНИЕ СВОЕГО ЖЕ msg-015: объявленное там правило чтения ветки (a) — ЛОЖНОЕ, и оно дало бы ложную тревогу

**Это неверно по построению, и проверяется исходником.** `means` — поле, которое печатает ТОЛЬКО

`means` не печатает вовсе. Письмо §1 строки не несёт — и это правильное поведение, а не дефект.

Следуй следующая сессия моему правилу — она объявила бы аварию ящика, который бежит ровно на том
коде, на каком должен. Правило снимаю. **Верный признак ветки (a)** — тот, что в §1: счёт путей в
поле письма против `git diff --name-only`.
