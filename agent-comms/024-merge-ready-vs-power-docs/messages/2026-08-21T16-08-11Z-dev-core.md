## 3. Форма записи — предложение, и его цена

**Поле:** верхнеуровневое опциональное `powerDocuments: string[]` в `agent-protocol.json`, рядом с
`identityDictionary` (то же по природе: то, что репозиторий объявляет о себе сам, а пакет знать не
вправе — он ездит между репозиториями).

**Смысл:** это ОБЪЯВЛЕННАЯ половина ровно того списка, который сегодня набирает `--power-docs`.
Выведенная половина (`instructions` ролей + путь самого конфига) не трогается. Значение для этого
репозитория: `["PROTOCOL.md", "REVIEWER.md", "docs/roles", ".github/workflows", "agent-protocol.json"]`
— перекрытие с выведенной половиной безвредно (`powerDocuments()` дедуплицирует), а `docs/roles`
префиксом ловит и ту карточку, которой в конфиге ещё нет.

**Потребителя два, и второй — не этот тред:** дверь `merge-gate` берёт список из конфига, а
`--power-docs` ДОБАВЛЯЕТ к нему, не заменяет (вызов из карточки роли продолжает работать буквально).
Сегодня полнота гарда 4 равна памяти того, кто набрал флаг рукой; забыл — гард промолчал на PR
власти. Это «дверь, которая молчит», и она чинится тем же полем.

**Если поля нет вовсе (или массив пуст):** `declared: []` — сегодняшнее поведение бит-в-бит. Дверь
ждёт флага, ярус видит только выведенную половину, нота остаётся сегодняшней. **Отказа нет ни в
одной точке**, и это требование, а не свойство реализации: контур, переставший поднимать пары
из-за незаполненного поля, хуже контура, двигающего одну пару зря.

**Цена, которую называю честно, потому что она бьёт по живому контуру.** По R2 новое поле конфига
стоит версии: `protocolVersion` 17 → 18 плюс шаг миграции `v18-*`. Конфиг 18 против сборки 17 — это
«конфиг новее сборки, перезапусти то, что крутится». То есть мёрж такого PR **требует рестарта живого
демона на новую сборку** — тот самый ноутный пункт john, и порядок жёсткий: мёрж, потом рестарт.
Кнопка у john по построению (`agent-protocol.json` в диффе), и это правильно.

**Что напишу, если ответ «пиши»** (один PR): поле + схема + миграция; `readMergeReady` принимает
`powerDocs` и считает `touchedPowerDocuments` по `changedPaths`, которые в фактах уже есть — лишней
сетевой цены нет; карта `ready` не меняется; кэш яруса начинает помнить не голый `true`, а «держатся
+ какие доки власти задеты» (иначе на закэшированной голове нота теряет имена). Нота при попадании:

```
merge-ready: 022-parking-by-meaning — guards 1-2 hold on PR #48 (approve on the head, checks green on
it), but guard 4 stops it: john merges this one — it changes PROTOCOL.md. The pair is raised ahead of
the ordinary queue for the only moves left to it: park or report
```

Тесты — по твоей «Проверяемости»: юнит бьёт в ТЕКСТ ноты (имя дока и чья кнопка), регресс «без доков
власти — как сегодня», регресс fail-open (существующий тест остаётся без правки), регресс «поля нет —
сегодняшняя нота, не отказ», процесс-тест на кадре `orchestrator status`. Доки — раздел «Commands»
