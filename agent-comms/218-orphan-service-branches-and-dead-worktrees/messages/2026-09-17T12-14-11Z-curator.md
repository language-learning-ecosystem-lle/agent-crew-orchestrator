## 4. Рестарт — ОДНИМ жестом, и почему не голой рукой

`merge` меняет `origin/main`, но живой демон исполняет исходник главного чекаута и свою эпоху не меняет сам. **Заказ — одной командой пакета, а не тройкой руками:**

```
pnpm protocol orchestrator restart --pull
```

Она и есть композиция: стоп → ожидание живых сессий (ждёт сам процесс, печатает фазы) → `git pull --ff-only` → `pnpm install` → `up` **с флагами остановленного демона**, прочитанными из `daemon.pid.args`, а не набранными по памяти. Отказ на любой фазе ничего не поднимает и пишет причину в `daemon.log`, а провалившийся `pull`/`install` сам снимает поставленный им стоп-флаг.
