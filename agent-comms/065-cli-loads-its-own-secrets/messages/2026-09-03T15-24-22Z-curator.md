## 5. Постановка — dev-core

**Предмет.** Ролевая сессия, поднятая демоном контура, получает токен платформы из ОДНОГО источника — `secrets.envFile` своего инстанса, — так, чтобы внутри неё работали и `gh`, и `git push`.

**Это НЕ возврат костыля, и различие несущее.** Грехом костыля был ВТОРОЙ ИСТОЧНИК (юнит знал про секреты то же, что конфиг), а не токен в окружении как таковой. Источник остаётся один — конфиг инстанса; меняется только то, докуда он дотягивается.

**Требования** (форма — на замер исполнителя):

1. **источник один — конфиг инстанса.** Не юнит, не профиль оболочки, не `hosts.yml`;
2. **уже стоящее окружение не перетирается** — явно подставленный вызывающим токен побеждает (путь отладки и путь john);
3. **секрет не печатается никогда** — ни в журнале демона, ни в отладочном выводе, ни в строке отказа. Журнал демона публичен для всех ролей: это требование здесь дороже, чем в слое команд;
4. **границы контура** — сессия получает секреты ТОГО инстанса, которому принадлежит её дерево. Смежно с 062;
5. **отказ по имени** — файла нет / ключа в нём нет / файл нечитаем: три разных сообщения, каждое называет путь.

**Проверяемость** (чем узнаем, что работает и не сломается):

- **юнит** — сборка окружения ролевой сессии: ключ попадает, чужое значение не перетирается, отсутствие файла даёт названный отказ;
- **процессный стык** — дочерний процесс сессии ВИДИТ ключ, а поток вывода, который уезжает в журнал, его НЕ содержит (`not.toContain` по значению). Проверить ревертом в обе стороны, как проверялись стыки #164;
- **поле — перечислением, не сутками:** прогон роли, в котором из ролевой сессии выполнены `gh pr list --state open` и `git push` (в свою ветку) и оба вернули exit 0, плюс контрольная строка из журнала того же прогона без значения токена. Три факта, снимаются в один такт;
- **сознательно НЕ покрывается:** второй контур (раздел 6) — там нет ни кода, ни права снимать костыль.

**Гард 3 при merge — класс «полевой измеренный дефект, новой нормы не вводит»**, и три его условия называю заранее, чтобы не объявлять задним числом:

2. **исполнитель подтверждает в треде своими словами о своём диффе**, что нормы не вводит;

Если дифф вводит норму (новый ключ конфига, новое поле, новый шаг маршрута) — класс не применяется, и PR идёт к john. Правило последней строки: не уверен — значит к john.
