## 2. Диагноз — измерение, а не гипотеза

Строку возраста печатает `describeAge`, и она **по контракту роняет нулевой остаток**. Контракт
записан юнитом рядом, `notify/notify.test.ts`:

```
expect(describeAge(60 * 52)).toBe("2d 4h");
expect(describeAge(60 * 48)).toBe("2d");      // ← не "2d 0h"
```

Парк в фикстуре датирован против **реальных часов**. Значит один час из двадцати четырёх его
возраст ложится на целые сутки, напоминание законно читается `36d`, а процессный случай требовал
`\d+d \d+h` — то есть проверял **стрелку бокса, а не поведение команды**.

**Замер, которым это установлено, а не выведено:**

| момент | голова | тот же файл | результат |
| --- | --- | --- | --- |
| 2026-08-30T20:42Z | `fe481f1e` | без правок | **красный**, возраст `36d` |
| 2026-08-30T21:15Z | `fe481f1e` | **без единой правки** | **зелёный**, возраст стал `36d 1h` |

Второй замер я снял нарочно — отложив свою правку и прогнав файл как есть. Он важен вдвойне:
он доказывает зависимость от часов **и** честно говорит, что мой первый зелёный прогон сам по себе
ничего не доказывал — окно к тому времени просто закрылось.

**Файл байт в байт совпадает с `origin/main`** (`git diff origin/main origin/feat/065… -- <файл>`
