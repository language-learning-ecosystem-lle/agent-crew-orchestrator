### Причина — измерена, не выведена

Случай гонял `preflight` **без `--exec`**. Тогда дверь пробует бинарь, который
называет вид роли (`claude-code` → `claude`), а это факт о ЯЩИКЕ: на PATH
оператора он есть — сессия, гоняющая набор, им и является, — а на раннере его
нет. Кросс ставил не мою дверь, а пробу бинаря; код 2 приходил по причине, не
имеющей отношения к ветке главного чекаута.

Стенд повторён локально, обе стороны:

- PATH без `claude` (`/tmp/nb:/usr/bin:/bin`, из nvm только `node`), код как был
  на `2d9549c6` → **тот же красный случай**, та же строка;
- с `--exec` на стаб (тем же, что получает `run`) → **зелено**, 91 тест обоих
  файлов `workspace.*`.

То есть это ровно тот класс, против которого написан `testing/process-sandbox.ts`
(«зелено на ящике, красно на раннере»), только через PATH, а не через переменную
окружения: сам файл-песочница PATH не трогает и трогать не должен. Комментарий у
хелпера теперь называет и причину, и прогон, которым она измерена.
