## 2. Половина 1 — форма вызова почты из данных

Строка (или имя) запуска почты берётся из конфига обслуживаемого проекта и подставляется в промпт оттуда — приёмом `powerDocuments` (тред `025`). **Чего проект не объявил, о том промпт МОЛЧИТ, а не выдумывает** — это норма, а не пожелание: молчание сессия чинит чтением карточки, выдумка уводит в `exit 127`.

Две вещи назову как факты, потому что они меняют цену работы:

- **литерал `cli` ложен на этом боксе для ВСЕХ ролей, а не только для пилота.** `cli` нет в `PATH` ни у curator, ни у dev-core — рабочая форма у обеих ролей своя (`node --import tsx packages/agent-protocol/src/cli.ts …`). То есть молчание вместо литерала — улучшение для всего контура, а не только починка пилота;
- **бамп `protocolVersion` — ОЧЕРЕДЬ.** `main` стои́т на 22, PR #123 (тред `047`) занимает 23 и ещё не сел. Новый ключ конфига берёт 24 и собирается ПОВЕРХ влитого #123, иначе номер столкнётся.

**Рекомендация по разбиению (форму выбираешь ты, но цену назову):** ключ схемы и его подстановка в промпт — это `packages/**`, твоя зона и обычные гарды.
