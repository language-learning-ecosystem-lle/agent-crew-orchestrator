## Второй круг: находка первого раунда (критерий 11) — проверена как починенная

Первый круг (прогон `33825172226`) назвал молчащую дверь: под вторым условием успеха (`before === after`) диф `before..HEAD` пуст независимо от реального расхождения `pnpm-lock.yaml` между загруженным кодом и деревом, и строка пропуска установки заявляла непомеренное. Дифф этого круга (коммиты `3fa0493d`, `e9aebd05`) меняет ровно это:

- `repairMoveVerdict` (`self-restart.ts:816-853`) у ветви `moved` возвращает `installFrom = input.loaded ?? input.before` и `installFromMeans` — единое правило без второй ветки на «каким условием зачтён сдвиг», что и есть честный широкий промежуток на случай «рука подтянула ДО и подтяжка сдвинула дальше»;
- `cli.ts:151-156` берёт дифф `move.installFrom..move.to`, а не `before..HEAD`;
- `describeInstallSkipped(span)` (`self-restart.ts:872-877`) печатает промежуток и его смысл, а не утверждение «pull moved none of» — фраза, дословно неверная под вторым условием, из потока убрана (проверено `expect(said).not.toContain("the pull moved none of")`).

Сценарий отказа воспроизведён по коду построчно (демон стартует с `loaded=A`, рука пуляет дерево `A→B` с новым `pnpm-lock.yaml`, `pull --ff-only` — no-op на уже стоящем дереве, `before===after===B`): под старым кодом `changed = diff(B,B) = []` → install пропущен молча; под новым — `changed = diff(loaded=A, B)` → реальное расхождение видно. Юнит `"anchors the install question at the loaded code, not at the tree the pull found"` и процессный `"asks the installer about the span from the LOADED code when a hand moved the tree"` ставят именно этот путь целиком, включая живой демон без `--once` (синхронизация по баннеру vintage, а не по сну) — и оба проверены на старом якоре (`installFrom: input.before`): юнит краснеет по SHA, процессный — по промежутку в потоке. Обычный путь (`loaded === before`) не задет: ассерт `"leaves the ordinary span alone…"` и версионный путь (`loaded` берётся из `read.sha` в тот же тик) сохраняют старое поведение по построению.

Новой находки класса «дверь молчит» в этой правке не нашёл: `installFrom` при неизвестном `loaded` откатывается на `before` с честной формулировкой («the tree as this repair found it»), а не выдаёт незнание за знание.
